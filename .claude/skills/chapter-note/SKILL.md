# 챕터 이해 노트 작성

대상 파일: $ARGUMENTS

노트 작성 규칙과 절차는 모두 프로젝트 `CLAUDE.md`에 있다. 이 스킬은 **입력 처리만** 정하고, 나머지는 CLAUDE.md의 "작업 절차"를 그대로 따른다.
CLAUDE.md의 내용을 여기에 옮기거나 다르게 해석하지 않는다.

## 1. 입력 확인
- 대상 파일이 비어 있거나, `textbook/` 아래의 PDF가 아니거나, 존재하지 않으면 멈추고 학습자에게 파일을 다시 요청한다.
- 파일 경로에서 다음을 알아낸다.
  - **교재 폴더**: `textbook/` 바로 아래 폴더 이름 (예: `textbook/회로이론/...` → `회로이론`)
  - **챕터 번호**: 파일명의 `제NN장` (예: `회로이론_제01장_전기이론.pdf` → `01`)
- 챕터 번호를 파일명에서 찾을 수 없으면 추측하지 말고 학습자에게 묻는다.

## 2. 과목 폴더 결정
- CLAUDE.md "폴더 구조"의 이름 대응표에서 교재 폴더에 해당하는 과목 폴더를 찾는다.
- 대응표에 없는 과목이면 영문 kebab-case 과목 폴더 이름을 제안하고, **학습자가 확인한 뒤** 대응표에 추가하고 진행한다.

## 3. 처음 시작인지, 이어서 하는지 판단
작업 메모 `.cache/work/{과목 폴더}/ch{챕터 번호}-plan.md`를 확인한다.
- **없으면**: CLAUDE.md "작업 절차"의 1단계부터 시작한다.
- **있으면**: 작업 메모의 진행 상황을 읽고 학습자에게 한 줄로 알린 뒤(예: "파트 2/4까지 완료 — 파트 3부터 이어간다") 남은 단계부터 이어간다.
  - 1단계의 학습자 확인을 아직 받지 않은 상태로 끝났다면, 큰 질문, 이야기 뼈대, 파트 계획을 다시 보여주고 확인을 받는다.
  - 이미 저장된 노트 파일과 작업 메모가 서로 맞지 않으면(예: 메모에는 완료인데 파일이 없다) 진행하지 말고 학습자에게 알린다.
- 노트가 이미 완성된 챕터(3단계까지 완료)라면 다시 쓰지 않고, 학습자에게 무엇을 할지 묻는다.

## 4. 진행
CLAUDE.md "작업 절차"의 1~3단계를 따른다.
