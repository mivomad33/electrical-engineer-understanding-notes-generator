# 챕터 이해 노트 작성

대상 파일: $ARGUMENTS

**노트가 어떤 모습이어야 하는지**(목적, 노트 구조, 기호, 수식, 문체)는 프로젝트 `CLAUDE.md`에 있다.
이 스킬은 **노트를 만드는 방법**(입력 처리, 교재 읽기, 작업 절차, 에이전트)을 정한다. 노트의 모습에 관한 규칙은 여기에 옮기지 않고 CLAUDE.md를 따른다.

## 입력 확인
- 대상 파일이 비어 있으면 아래 "대상 파일이 없을 때 — 다음 챕터 고르기"로 대상 파일을 정한다.
- 대상 파일이 `textbook/` 아래의 PDF가 아니거나 존재하지 않으면 멈추고 학습자에게 파일을 다시 요청한다.
- 파일 경로에서 다음을 알아낸다.
  - **교재 폴더**: `textbook/` 바로 아래 폴더 이름 (예: `textbook/회로이론/...` → `회로이론`)
  - **챕터 번호**: 파일명의 `제NN장` (예: `회로이론_제01장_전기이론.pdf` → `01`)
- 챕터 번호를 파일명에서 찾을 수 없으면 추측하지 말고 학습자에게 묻는다.

### 대상 파일이 없을 때 — 다음 챕터 고르기
학습자가 교재 PDF를 `textbook/{과목}/`에 넣어 두고 스킬만 부르면, 아직 노트를 끝내지 않은 챕터 중 첫 번째를 골라 **제안**한다. 한 번에 한 챕터만 고른다 (챕터 하나가 큰 작업이므로).
1. **후보 교재**: `textbook/*/` 바로 아래에서 파일명이 `{폴더 이름}_제{두 자리 숫자}장_*.pdf` 형식인 파일만 모은다. 형식이 다른 PDF(부록, 모의고사 등)는 빼되, 뺀 파일이 있으면 제안할 때 이름을 함께 알린다.
2. **완료 여부**: 후보마다 과목 폴더(아래 "과목 폴더 결정"의 대응표, 대응표에 없으면 아직 시작하지 않은 과목)를 찾고, `notes/{과목 폴더}/_index.md`의 "챕터 목차"에 그 챕터의 행이 있으면 **완료**다. 행은 챕터 번호의 숫자 값으로 찾는다 (파일명 `제04장` ↔ 목차 행 `4장 …`). 4단계가 끝날 때에만 목차에 추가하므로, 목차에 있으면 4단계까지 마친 챕터다.
   - 노트 파일이나 작업 파일이 있어도 목차에 없으면 **미완료**다 (쓰다 만 챕터). 노트 파일 존재로 판단하면 쓰다 만 챕터를 건너뛰고 다음 챕터로 넘어가, 앞 챕터를 링크해야 하는 뒤 챕터를 먼저 쓰게 된다.
   - 과목 `_index.md`가 없으면 그 과목의 챕터는 모두 미완료다.
   - 목차에는 없는데 `_index.md`의 다른 절(페이지 지도, 기호 약속 등)에 그 챕터를 끝낸 흔적이 있으면, 규칙대로 미완료로 두되 확인 질문에서 "목차 행만 빠졌을 수 있다"고 함께 알린다.
3. **고르기**: 미완료 후보를 과목과 상관없이 하나의 목록에 놓고, 과목은 `tools/subjects.json`에 적힌 순서(공부 순서: 기초 과목이 먼저), 같은 과목 안에서는 장 번호 순서로 정렬해 첫 번째를 고른다. `subjects.json`에 없는 과목은 맨 뒤에 둔다.
4. **확인받기**: 진행하기 전에 학습자에게 묻고, 확인을 받은 뒤에만 그 파일을 대상 파일로 삼아 아래로 진행한다. 질문에는 다음을 넣는다.
   - 고른 파일과 상태: 새로 시작인지, 이어서 하는지. 판단은 아래 "처음 시작인지, 이어서 하는지 판단"과 같은 기준으로 미리 해 보고, 이어서 하는 경우 `plan.md`의 진행 상황 한 줄을 넣는다. `plan.md`와 노트 파일이 맞지 않거나 진행 상황을 읽을 수 없으면 그렇다고 적는다.
   - 고른 챕터를 포함한 미완료 챕터 수(전 과목 기준), 그다음 후보 최대 3개 (없으면 "없음")
   - 대응표에 없는 과목이면 제안하는 과목 폴더 이름 (아래 "과목 폴더 결정"). 챕터 확인과 같은 질문에서 함께 묻는다. 대응표에 이미 있으면 다시 묻지 않는다 (노트를 아직 시작하지 않은 과목이어도).
   - 학습자가 다른 챕터를 원하면 그 파일로 진행한다.
5. 미완료 후보가 없으면 "남은 교재가 없다"고 알리고 끝낸다 (완료한 챕터 수와 뺀 파일이 있으면 함께).

## 과목 폴더 결정
- CLAUDE.md "폴더 구조"의 이름 대응표에서 교재 폴더에 해당하는 과목 폴더를 찾는다.
- 대응표와 `tools/subjects.json`이 다르면 진행하지 말고 학습자에게 알린다.
- 대응표에 없는 과목이면 영문 kebab-case 과목 폴더 이름을 제안하고, **학습자가 확인한 뒤** 대응표와 `tools/subjects.json`에 추가하고 진행한다.

## 처음 시작인지, 이어서 하는지 판단
작업 파일 `.cache/work/{과목 폴더}/ch{챕터 번호}-plan.md`와 `ch{챕터 번호}-scope.md`를 확인한다.
- **둘 다 없으면**: 아래 "작업 절차"의 1단계(범위 추출)부터 시작한다.
- **있으면**: `plan.md`의 진행 상황을 읽고 학습자에게 한 줄로 알린 뒤(예: "파트 2/4까지 완료 — 파트 3부터 이어간다") 남은 단계부터 이어간다.
  - `scope.md`가 없거나 일부 묶음이 빠져 있으면 1단계부터 다시 한다.
  - `scope.md`에 "그림" 절이 없으면(그림 넣기 규칙이 생기기 전에 시작한 챕터) 1단계의 "교재 그림 추출"만 하고, 그림을 마디에 배정해 `plan.md`에 더한 뒤 이어간다. 이미 쓴 파트에는 그림을 넣고 파트 검증의 "그림" 항목으로 확인한다.
  - 2단계의 학습자 확인을 아직 받지 않은 상태로 끝났다면, 큰 질문, 이야기 뼈대, 파트 계획을 다시 보여주고 확인을 받는다.
  - 이미 저장된 노트 파일과 `plan.md`가 서로 맞지 않으면(예: 메모에는 완료인데 파일이 없다) 진행하지 말고 학습자에게 알린다.
- 노트가 이미 완성된 챕터(4단계까지 완료)라면 다시 쓰지 않고, 학습자에게 무엇을 할지 묻는다.

## 교재 읽기 — 범위 추출

교재는 **범위 목록**을 만들 때만 읽는다. 노트를 쓰는 동안에는 교재가 아니라 범위 목록을 본다.

### 범위 목록
`.cache/work/{과목 폴더}/ch{챕터 번호}-scope.md`에 교재 절 순서대로 아래 항목을 뽑아 적는다.
- **개념·원리·규칙**: 공식이 아닌 것도 모두 (예: "전류계는 회로에 직렬로 연결한다")
- **공식**: 교재에 쓰인 형태·기호 그대로 (시험 표기의 근거가 되므로 정확해야 한다)
- **용어·상수**: 교재가 쓰는 용어, 상수와 환산값
- **기출 문제에서만 나오는 것**: 본문에 없는 개념이나 공식 변형이 문제에서 쓰이면 범위에 포함한다 (예: 평형 브리지에서 가운데 저항을 없애도 되는 이유, $R_s = \frac{R_a}{n-1}$ ↔ $n = 1 + \frac{R_a}{R_s}$). 문제·보기·정답 자체는 옮기지 않는다.
- 항목마다 PDF 페이지를 적는다.

다음은 범위에 넣지 않는다.
- 설명 없이 나열만 된 참고 페이지(표지, 목차, 그리스 문자표, 단위 배수표 등). 단위 배수($\text{m}$, $\mu$, $\text{k}$ 등)는 노트에서 처음 등장할 때 짧게 짚는다.
- 워터마크와 불필요한 문구 (CLAUDE.md "교재를 다룰 때 공통 규칙" 참고).

### PDF 읽는 방법
교재 PDF는 텍스트 레이어에서 **수식이 대부분 깨지거나 빠진다** (분수·그리스 문자·첨자가 빈칸이나 깨진 글자로 나온다). 반면 한글 문장과 일반 숫자·단위는 비교적 정확하다.
그래서 **텍스트는 구조 파악과 교차 검증용, 이미지는 내용 판독용**으로 나눠 쓴다.
교재 파일명에는 공백이 들어 있으므로(예: `회로이론_제02장_정현파 교류.pdf`) 아래 명령에서 PDF 경로는 반드시 따옴표로 감싼다.

1. **구조 파악 — 텍스트**: `pdftotext`로 페이지마다 절 제목을 뽑아 "교재 절 → PDF 페이지" 지도를 만든다.
   ```bash
   pdftotext -f {페이지} -l {페이지} -layout "textbook/{교재 폴더}/{파일}.pdf" -
   ```
   기출 문제 페이지처럼 **좌우 2단 편집**인 페이지는 `-layout`을 쓰면 두 단의 줄이 섞이므로, `-layout` 없이 추출하거나 이미지로만 판단한다.
2. **렌더링 — 챕터 전체**: 페이지를 골라 렌더링하지 말고 챕터 PDF 전체를 렌더링한다. 이미 있으면 재사용하고, 작업이 끝나도 지우지 않는다.
   ```bash
   pdftoppm -png -r 150 "textbook/{교재 폴더}/{파일}.pdf" .cache/pages/{과목 폴더}/ch{챕터 번호}
   ```
3. **내용 판독 — 이미지**: 본문 페이지는 **전부** 이미지로 읽는다. 공식은 반드시 이미지에서 옮긴다.
4. **애매하면 확대**: 첨자·지수·작은 기호가 애매하면 해당 영역만 300dpi로 잘라 다시 본다. `-x -y -W -H`는 300dpi 기준 픽셀이므로 150dpi 이미지에서 찾은 좌표에 2를 곱한다. 결과 파일은 `zoom-ch01-06.png` 형태가 된다(같은 페이지를 다시 확대하면 덮어쓴다).
   ```bash
   pdftoppm -png -r 300 -f {페이지} -l {페이지} -x {X} -y {Y} -W {폭} -H {높이} "textbook/{교재 폴더}/{파일}.pdf" .cache/pages/{과목 폴더}/zoom-ch{챕터 번호}
   ```
   확대해도 애매하면 추측하지 말고 범위 목록에 `⚠️ 판독 불확실: PDF p.XX`로 표시한다.
5. **교차 검증**: 이미지에서 읽은 숫자·단위·용어는 같은 페이지의 텍스트 추출 결과와 대조한다. 다르면 이미지를 확대해 다시 확인한다.

## 작업 절차

챕터 노트는 한 번에 요청받더라도 아래 4단계로 나눠 진행한다.
긴 챕터를 한꺼번에 처리하면 대화가 길어져 앞쪽 세부가 흐려지고, 마지막에 몰아서 하는 검증이 형식적이 되기 때문이다.
대화가 요약되거나 끊겨도 이어갈 수 있도록, 단계마다 결과를 작업 파일(`scope.md`, `plan.md`)에 남긴다.

### 1단계 — 범위 추출
1. 텍스트 추출로 페이지 지도를 만들고, 챕터 전체를 렌더링한다. 페이지 지도는 `plan.md`에 적는다.
   그리고 아래 "교재 그림 추출"로 이 챕터의 필수 그림 목록을 만든다.
2. 페이지 지도를 교재 본문 약 10~15페이지씩 묶어, 묶음마다 **범위 추출 에이전트**에게 맡긴다 (아래 "에이전트" 참고). 묶음이 여럿이면 동시에 실행한다.
   묶음 경계는 **교재 절 경계**에 맞춘다. 한 절이 두 묶음에 걸치면 항목이 중복되거나 빠질 수 있기 때문이다. 절 하나가 15페이지를 넘으면 그 절만 소제목 경계에서 나눈다.
3. 결과를 교재 절 순서대로 합쳐 `scope.md`에 저장한다.
4. **범위 목록이 교재를 빠짐없이 담았는지 점검한다.** 범위 목록에서 빠진 것은 노트에서도 조용히 사라지기 때문이다.
   - 챕터 전체의 텍스트 추출 결과와 대조해, 교재의 모든 절·소제목·TIP 상자와 교재가 정의하거나 설명하는 용어에 대응하는 범위 항목이 하나 이상 있는지 확인한다. 한글 텍스트는 정확하게 추출되므로 이미지를 볼 필요가 없다.
   - 빠진 것이 있으면 해당 페이지 이미지를 보고 범위 항목을 추가한다.

### 교재 그림 추출 (1단계 안에서)
노트에는 교재의 그림을 **빠짐없이** 넣는다 (CLAUDE.md "노트 구조 > 교재 그림은 모두 넣는다"). 그림을 자르는 일은 `tools/textbook-figures`가 하고, 여기서는 그 결과가 맞는지 확인한다. 사용법·판정 규칙은 `tools/textbook-figures/README.md`.
1. 도구를 실행한다.
   ```bash
   cd tools/textbook-figures && uv run --quiet textbook_figures.py "../../textbook/{교재 폴더}/{파일}.pdf"
   ```
   결과: `notes/{과목 폴더}/figures/ch{챕터 번호}/`의 그림 PNG와 `figures.json`(필수 그림 목록), `.cache/work/{과목 폴더}/ch{챕터 번호}-figures/sheet-*.png`(점검 이미지).
2. **점검 이미지를 모두 본다.** 쪽마다 찾은 그림이 색 상자로 표시되어 있다 (빨강 캡션 그림, 초록 그림이 든 표, 파랑 캡션 없는 그림, 보라 직접 지정, 회색 그림 없는 표). 다음을 찾는다.
   - 상자가 없는 그림 (빠짐), 그림 일부를 자른 상자, 본문 문단까지 삼킨 상자, 그림이 아닌 것을 잡은 파랑 상자 (공식, 표지 글자 등), 그림이 들었는데 회색인 표.
   - 애매하면 `figures/ch{챕터 번호}/{id}.png`를 직접 연다.
3. 문제가 있으면 `tools/textbook-figures/manual.json`에 고칠 내용(빼기 `exclude`, 영역 고치기 `rect`, 더하기 `add`)을 적고 1부터 다시 실행한다. 여러 챕터에 같은 문제가 보이면 manual.json 대신 도구의 판정 규칙을 고친다.
4. 경고 없이 끝나고 점검 이미지에 문제가 없을 때까지 반복한다. 고친 내용을 `plan.md`에 한 줄씩 적는다.
5. `figures.json`의 필수 그림을 범위 목록처럼 다룬다: 그림마다 무엇을 보여 주는 그림인지 한 줄로 `scope.md` 끝의 "그림" 절에 적는다 (id, 쪽, 내용). 2단계에서 마디에 배정하기 위함이다.

### 2단계 — 설계 (학습자 확인 필요)
1. **과목 `_index.md`를 읽는다** (첫 챕터라 없으면 건너뛴다). 앞 챕터들의 한 줄 요약(이미 설명한 개념), 기호 약속, "나중에 연결할 곳"을 확인한다. 다른 과목 노트가 있으면 그 과목 `_index.md`의 기호 약속도 확인한다 (CLAUDE.md "기호" 절 참고). 이미 설명한 개념을 처음부터 다시 설명하거나, 앞에서 정한 기호와 다른 기호를 쓰지 않기 위함이다.
2. `scope.md`를 보고 **큰 질문**과 **이야기 뼈대**를 설계한다 (CLAUDE.md "노트 구조 > 이야기 뼈대는 처음부터 설계한다" 기준). 앞 챕터에서 이미 설명한 개념은 뼈대에서 짧게 되짚는 자리로만 둔다.
3. 범위 목록의 모든 항목을 뼈대의 마디에 배정한다. 어느 마디에도 들어가지 않는 항목이 있으면 뼈대를 고친다.
   **필수 그림도 모두 마디에 배정한다** (그림이 보여 주는 개념을 설명하는 마디). 그림 하나는 한 곳에만 넣는다.
4. **이 챕터에서 쓸 주요 기호**를 정한다 (CLAUDE.md "기호" 절 기준). 앞 챕터의 기호 약속을 따르고, 새로 정하는 기호는 교재 기호와 다르면 그 교재 기호도 함께 적는다. 파트마다 기호가 달라지지 않게 하고, 4단계에서 `_index.md`의 기호 약속으로 옮길 근거로 삼기 위함이다. 집필 중 새 기호가 필요해지면 `plan.md`에 추가한다.
5. 마디 경계에서 **파트**를 나눈다. 한 파트는 교재 본문 약 10~15페이지에 해당하는 분량이다. 범위가 그보다 작으면 파트 하나로 한다.
6. 큰 질문, 뼈대(마디별 배정 항목 포함), 기호, 파트 계획을 `plan.md`에 저장한다.
7. 큰 질문, 이야기 뼈대, 파트 계획을 학습자에게 짧게 보여준다. 뼈대에는 **각 마디가 왜 그 자리에 오는지**(어떤 선수 관계 때문인지)를 함께 보여준다. **학습자가 확인한 뒤** 3단계로 넘어간다 (뼈대가 틀리면 노트 전체를 다시 써야 하므로).

### 3단계 — 집필 (멈추지 않고 연속 진행)
학습자 확인 이후에는 파트마다 멈춰서 묻지 않고 끝까지 이어간다.
- **예외 — 멈추고 묻는다**: 확인받은 뼈대나 파트 계획을 바꿔야 할 정도의 문제를 발견한 경우 (예: 마디 순서를 바꿔야 논리가 이어진다, 뼈대로는 설명할 수 없는 항목이 있다).
- **기록하고 계속한다**: 그 밖의 것(사소한 판단, 교재 오류로 보이는 것 등)은 `plan.md`에 기록하고 진행한다.

각 파트마다:
1. **이전 파트 파일을 읽는다** (첫 파트는 건너뛴다). 이전 파트가 어떤 질문을 남기고 끝났는지, 어떤 개념·용어를 이미 설명했는지 확인한다. 기억에 의존하지 않고 파일을 직접 읽는다.
2. `plan.md`와 `scope.md`에서 이 파트 마디에 배정된 범위 항목과 그림을 확인한다. 교재 페이지는 다시 읽지 않는다 (`⚠️ 판독 불확실` 항목만 예외로 이미지를 다시 확인한다).
3. 노트 파일을 작성해 저장한다. 배정된 그림은 CLAUDE.md "교재 그림은 모두 넣는다"의 형식으로 넣는다. 그림을 넣기 전에 그 PNG를 직접 열어 보고, 그림 속 기호·라벨이 노트의 기호와 다르면 시험 표기를 단다. 아직 없는 노트로 연결할 자리가 생기면(CLAUDE.md "부록 > 연결" 참고) 그 자리를 `plan.md`의 "나중에 연결할 곳" 목록에 바로 적는다 (노트 파일·위치, 연결 대상 챕터·과목, 연결할 개념). 4단계에서 파일을 다시 훑으며 찾다 보면 빠뜨리기 쉽고, 대화가 끊겨도 기록이 남게 하기 위함이다.
4. **파트 검증 에이전트**로 검증한다. 지적 사항을 확인해 고친다. 반영하지 않은 지적은 이유와 함께 `plan.md`에 기록한다.
5. `plan.md`의 진행 상황을 갱신하고, 학습자에게 한 줄로 보고한다 (예: "파트 2/4 완료 — 옴의 법칙~분압·분류, 검증 지적 3건 수정").

### 4단계 — 마무리
1. **그림 누락 점검**: 아래 명령이 「통과」해야 한다. 빠진 그림, 두 번 넣은 그림, 없는 파일을 가리키는 그림을 찾는다. 실패하면 고친 뒤 다시 실행한다.
   ```bash
   cd tools/textbook-figures && uv run --quiet textbook_figures.py --check ../../notes/{과목 폴더}/{노트 파일 하나}.md
   ```
2. 모든 파트 파일을 읽고, 마지막 파트 파일의 본문 뒤에 부록(정리, 교재 범위 대응표, 스스로 설명해보기, 연결)을 CLAUDE.md "노트 구조 > 부록"대로 쓴다.
3. **챕터 전체 검토 에이전트**로 검토한다. 지적 사항을 확인해 고치고, 반영하지 않은 지적은 이유와 함께 `plan.md`에 기록한다.
4. 과목 `_index.md`를 갱신한다 (목차, `plan.md`의 페이지 지도, `plan.md`에 기록한 기호 중 새로 정한 것, `plan.md`에 모은 "나중에 연결할 곳"). 새 과목이면 `notes/_index.md`도 갱신한다.
5. **밀린 연결을 채운다.** 과목 `_index.md`(다른 과목이면 그 과목의 `_index.md`도)의 "나중에 연결할 곳" 중 이 챕터를 기다리던 항목이 있으면, 이전 노트의 해당 위치에 링크를 걸고 그 항목을 목록에서 지운다.
6. **필기용 PDF를 만든다.** `node tools/note-pdf/note_pdf.mjs <이 챕터의 노트 파일 하나>`로 노트와 기출 문제지를 묶은 챕터 PDF 한 권을 만든다 (문제지가 없으면 note-pdf가 exam-sheets를 자동으로 돌린다). 5번에서 이전 챕터 노트를 고쳤으면 그 챕터도 같은 방법으로 다시 만든다. 학습자가 노트를 아이패드에서 필기하며 공부하므로, 노트가 바뀌면 PDF도 함께 맞춰 두기 위함이다. 실패하거나 경고가 나와도 노트 작업은 끝난 것으로 보고, 결과 보고에 그 내용을 적는다. 사용법은 `tools/note-pdf/README.md`.
7. 챕터 결과를 짧게 보고한다: 파트 수, 넣은 그림 수(manual.json으로 고친 것 포함), 검증·검토에서 고친 것, 채운 연결, **반영하지 않은 지적과 그 이유**, `⚠️ 판독 불확실`이 남은 것, 교재 오류로 보이는 것, 만든 PDF 경로(다시 만든 이전 챕터 PDF 포함).
   반영하지 않은 지적도 보고하는 이유: 작성자가 혼자 기각하면 별도 검증을 둔 의미가 없어지므로, 최종 판단은 학습자가 볼 수 있게 한다.

## 에이전트

세 에이전트 모두 **작업 맥락이 없는 새 에이전트**로 실행한다. 쓴 쪽의 착각이 그대로 넘어가지 않게 하기 위함이다.
검증·검토 에이전트는 노트를 **직접 고치지 않고** 지적 목록(파일·위치, 문제, 근거)만 돌려준다. 수정 여부는 노트를 쓴 쪽이 판단한다.

### 범위 추출 에이전트 (1단계)
- 넘기는 것: 맡은 PDF 페이지 범위, 해당 페이지 이미지 경로, PDF 경로, 이 스킬 파일(`.claude/skills/chapter-note/SKILL.md`)의 "교재 읽기 — 범위 추출" 절, `CLAUDE.md`의 "교재를 다룰 때 공통 규칙" 절.
- 할 일: 맡은 페이지에서 범위 항목을 뽑아 범위 목록 형식으로 돌려준다. 공식은 이미지에서 형태·기호 그대로 옮기고, 애매하면 확대하고, 그래도 애매하면 `⚠️`로 표시한다. 워터마크·불필요한 문구는 넣지 않는다.

### 파트 검증 에이전트 (3단계)
- 넘기는 것: 검증할 노트 파일 경로, `scope.md`·`plan.md` 경로, 그림 폴더 `notes/{과목 폴더}/figures/ch{챕터 번호}/`, 과목 `_index.md` 경로(있으면, 기호 약속 대조용. 다른 과목 노트가 있으면 그 과목의 `_index.md`도), 교재 페이지 이미지 폴더와 PDF 경로(시험 표기 대조용), `CLAUDE.md`의 "노트 구조", "기호", "수식 작성 규칙", "문체", "교재를 다룰 때 공통 규칙" 절, 이 스킬 파일의 "교재 읽기 — 범위 추출" 절.
- 할 일:
  - **정확성**: 노트의 모든 설명과 공식이 일반적으로 확립된 물리·전기 지식에 맞는지 확인한다. 유도 단계, 수치 예시, 환산값은 직접 다시 계산한다 (필요하면 python). 정의·측정값으로 밝힌 것이 실제로 그런지도 확인한다.
  - **범위**: 이 파트 마디에 배정된 범위 항목이 모두 다뤄졌는지 확인한다. 공식이 아닌 개념·원리·규칙도 확인한다. 이해에 필요 없는 심화로 번진 곳도 지적한다.
  - **시험 표기**: 노트와 교재의 공식 형태·기호·용어가 다른 곳에 시험 표기가 연결되어 있는지 확인한다. 그리고 이 파트의 시험 표기는 `scope.md`만 믿지 말고 **표기에 적힌 PDF 페이지 이미지와 직접 대조**한다. 범위 추출 때 첨자 하나를 잘못 읽으면 그 오류가 노트까지 내려오고, 수식은 텍스트 추출로 교차 검증할 수 없기 때문이다. 애매하면 "교재 읽기 — 범위 추출"의 확대 방법을 쓴다.
  - **흐름**: 이야기가 끊기는 곳을 찾는다 (연결 없이 갑자기 등장하는 개념, 설명하기 전에 쓰인 용어, 공식이 먼저 나오고 설명이 뒤따르는 곳, 이야기를 앞으로 보내지 않는 문단).
  - **문체**: CLAUDE.md "문체" 절을 지키는지 확인한다. 특히 교재 문장을 그대로 옮기거나 살짝 바꿔 옮긴 곳이 없는지 교재 페이지 이미지와 대조한다. 정확성을 해치는 비유, 한계를 밝히지 않은 비유도 지적한다.
  - **기호**: `plan.md`에 정한 기호와 과목 `_index.md`의 기호 약속을 따르는지 확인한다.
  - **그림**: 이 파트 마디에 배정된 그림이 모두 들어갔는지, 각 그림이 그 내용을 설명하는 문단 바로 뒤에 있는지, 캡션 형식이 맞는지 확인한다. 그림 PNG를 직접 열어, 본문 설명이 그림과 맞는지(그림이 보여 주지 않는 것을 보여 준다고 쓰지 않았는지), 그림 속 기호·라벨이 노트 기호와 다른데 시험 표기가 빠진 곳이 없는지 본다.

### 챕터 전체 검토 에이전트 (4단계)
- 넘기는 것: 챕터의 모든 노트 파일 경로, `scope.md`·`plan.md` 경로, `CLAUDE.md`의 "노트 구조" 절, 그림 점검 명령(4단계 1번).
- 할 일:
  - **전체 흐름**: 큰 질문에서 마지막 마디까지 하나의 이야기로 읽히는지 확인한다.
  - **파트 경계**: 각 파일의 첫 단락이 이전 파일이 남긴 질문을 이어받는지 확인한다.
  - **중복과 선후 관계**: 같은 개념을 여러 번 설명하는 곳, 뒤에서 설명할 개념을 앞에서 미리 쓰는 곳을 찾는다.
  - **범위 전체**: 범위 목록의 모든 항목이 노트 어딘가에서 다뤄졌는지 확인한다.
  - **그림**: 4단계 1번의 `--check`를 직접 실행해 「통과」인지 확인한다. 그림이 이야기의 흐름과 맞는 자리에 있는지도 본다.
  - **부록**: 정리가 본문의 개념·원리·규칙·공식을 빠짐없이 담는지(공식이 아닌 원리 포함), 교재 범위 대응표가 범위 목록의 모든 항목을 담는지 확인한다.
  - **링크**: 본문과 부록의 **모든 링크**가 맞는 곳을 가리키는지 확인한다. 첫 파일 뼈대의 마디 링크(각 마디가 들어 있는 파일의 해당 제목), 각 파일 맨 위의 이전·다음 파일 링크, 본문의 다른 챕터·과목 링크, 정리·대응표의 링크를 모두 본다. 아직 없는 노트로 링크를 걸지 않았는지, 링크 없이 아직 없는 챕터를 언급한 곳이 모두 `plan.md`의 "나중에 연결할 곳"에 기록되었는지도 확인한다.
