# 교재 그림을 노트에 넣기

- 날짜: 2026-10-25
- 상태: 완료

## 배경

챕터 노트(md)와 필기용 PDF(note-pdf)에는 지금까지 교재 그림이 없었다. 회로도·파형·벡터도는 글로 묘사하면 이해하기 어렵고, 시험 문제도 교재와 같은 모양의 그림으로 나온다.
그래서 교재 본문의 그림을 **빠짐없이** 잘라 노트의 알맞은 자리에 넣기로 했다.

학습자와 정한 것:

- 별도 스킬이 아니라 **도구 하나**(`tools/textbook-figures`)를 만들고, 그림 단계는 `/chapter-note` 스킬에, 노트 모습에 관한 규칙은 `CLAUDE.md`에 넣는다. 그림은 챕터 노트를 쓰는 흐름 안에서 들어가야 하기 때문이다.
- **이미 쓴 노트(회로이론 1~3장)는 고치지 않는다.** 다음 챕터부터 적용한다. 필요하면 학습자가 1~3장을 지우고 다시 만든다.
- 명세서(write-spec) 없이 바로 진행하고, 이 문서로 기록한다.
- 그림은 교재 저작물이므로 **git에 올리지 않는다.** 도구를 다시 실행하면 같은 그림이 만들어진다.
- 그림은 **모두** 넣는다. 고르는 기준을 두면 빠지는 그림이 생기고, 그 판단을 매번 하는 것보다 다 넣는 편이 단순하다.

## 분석 결과

### 챕터 PDF의 개인정보·불필요한 문구

- 챕터 PDF 전체(940쪽)에 대각선 워터마크 글자는 없다.
- 맨 위의 구매자 응원 문구 띠는 약 24쪽에 남아 있고, 위치는 쪽 맨 위 y 8~20pt다. 본문은 y 60pt 아래에서 시작한다.
- 그래서 잘라 낼 영역은 본문 영역(위 60pt, 아래 60pt, 오른쪽 장 번호 탭 45pt를 뺀 곳) 안으로 한정하고, 영역에 개인정보로 보이는 글자가 있으면 멈추는 검사를 둔다.

### 그림의 종류

교재 다섯 권(과목 여섯 개, 54장)을 훑어 본 그림은 네 가지다.

| 종류 | 예 | 처리 |
|---|---|---|
| 캡션 그림 | 「그림 4-1 …」이 아래에 붙은 그림 | 필수 `fig4-1` |
| 그림이 든 표 | 칸 안에 소자 기호·파형·사진이 있는 「표 N-M」 | 필수 `tab4-2` (마크다운 표로 옮길 수 없다) |
| 캡션 없는 그림 | TIP 상자 안 도식, 테브난·노튼 단계별 회로, 벡터도 | 필수 `p05-1` |
| 글만 든 표, 표시 없는 표 | 「표 N-M」 중 글·수식뿐인 표, 루스 표, 공식 상자 | 후보 (노트가 다시 쓴다) |

### 판정에 쓸 수 있는 신호

PDF는 벡터 도형과 글자 정보를 그대로 갖고 있어서 그림을 찾을 수 있다 (PyMuPDF의 `get_drawings`, `get_image_info`, `get_text("dict")`).

- **캡션**: 「그림 N-M」으로 시작하고 첫 글자가 8pt 안팎인 줄. 본문 글자는 9~10pt다.
- **글꼴**: 그림 속 라벨은 대부분 바탕체 계열(`Batang`, `BatangChe`)이고, 본문·소제목·수식은 이 글꼴을 쓰지 않는다. 전 과목에서 바탕체 글자의 대부분이 그림 안에 있었고, 그림 밖에 있던 것은 자동 판정이 놓친 라벨이었다. 그래서 바탕체 줄은 길어도 라벨로 본다.
- **글자 크기**: 본문은 9pt 이상이다. 8.5~8.9pt 글자는 그림 라벨에만 나온다 (전 과목 줄 크기 분포로 확인).
- **표**: 칸선은 가로·세로 선과 사각형뿐이다. 그림은 곡선·사선·이미지를 갖는다.
- **공식 도형**: 분수 막대(위아래에 분자·분모), 글자 뒤 형광 띠(칠만 한 사각형을 글자가 덮는다), 행렬·절댓값 괄호 막대(칠한 가는 세로 사각형 — 전 과목 그림 안에는 하나도 없다), 밑줄, 공식 테두리 상자.

### 자동 판정이 틀린 유형과 대응

전 과목 점검 이미지를 과목별 에이전트가 모두 보고 문제를 모은 뒤(1차 약 130건), 공통 유형을 규칙으로 고쳤다.

| 유형 | 원인 | 대응 |
|---|---|---|
| 하위 그림 (a)(b)가 따로 잡힘 | 하위 그림 사이 소제목 줄이 사슬을 끊음 | 작은 글자·바탕체 줄은 사슬의 틈을 이어 준다 |
| 그림 오른쪽 라벨·범례가 잘림 | 긴 라벨을 본문 줄로 봄 | 바탕체 줄은 길이와 상관없이 라벨 |
| 위쪽 표가 그림에 딸려 들어감 | 표 칸선이 그림 사슬에 이어짐 | 표를 먼저 찾고 표의 도형·글자는 그림에서 뺀다 |
| 표 칸 안·표 바로 아래 캡션의 그림을 못 찾음 | 위 대응으로 표 도형이 빠짐 | 표 칸선(표 크기의 35% 이상)을 경계로 칸 안에서 찾고, 표는 후보로 내린다 |
| 나란한 그림의 경계가 틀림 | 두 캡션의 가운데에서 가름 | 두 캡션 사이에서 도형·라벨이 없는 가장 넓은 틈에서 가른다 |
| 공식 조각을 그림으로 봄 | 형광 띠·분수 막대·괄호 막대 | 공식 도형 판정 추가, 칸선뿐인 덩어리는 표시 없는 표(후보) |
| 캡션 윗부분이 잘린 그림에 들어감 | 여백(4pt)이 캡션에 걸침 | 잘라 낼 영역 아래 끝을 캡션 위로 제한 |
| 나란한 하위 그림 사이 화살표·× 줄에서 사슬이 끊김 | 본문 크기 수식 줄로 봄 | 화살표·× 기호 줄은 라벨로 보고, 사슬 잇기와 라벨 흡수를 더 바뀌지 않을 때까지 되풀이 |
| 다음 쪽으로 이어진 표(표 번호 없음)를 그림으로 봄 | 표 라벨이 앞 쪽에만 있음 | 본문 줄과 쪽 폭 가로선 2개 이상이 든 덩어리는 표시 없는 표 |
| 표 머리 칸의 대각선 하나 때문에 그림 든 표가 됨 | 사선을 그림 신호로 봄 | 사선 하나뿐인 표는 그림 없는 표 |

규칙으로 고치기 어려운 개별 배치(라벨이 멀리 떨어진 그림, 막대 그림처럼 글자가 굵은 본문 글꼴인 그림 등)는 `manual.json`으로 고친다.

점검 판단 기준으로 정한 것:

- **그림 옆 범례·기호 설명은 그림의 일부다.** 그림 속 기호의 뜻이 범례에만 있어서, 범례 없이 그림만 넣으면 노트가 기호를 다시 설명해야 한다. 범례가 캡션 줄과 겹쳐 한 사각형으로 자를 수 없으면(전기설비기술기준 4장 그림 4-10) 범례를 따로 잘라 `add`로 넣는다.
- 캡션 하나 위에 캡션 없는 상자가 여럿 있고 같은 그림의 부분이면(하위 그림 (a)(b)가 따로 잡힘) `merge`로 합친다.
- 그림이 든 표에서 머리 행이 빠졌으면 머리 행까지 넣는다 (칸 제목이 그림의 뜻을 정한다).

## 결정

- 도구: `tools/textbook-figures/textbook_figures.py` (uv, PyMuPDF). 사용법·판정 규칙·manual.json 형식은 [README](../../tools/textbook-figures/README.md).
- 결과 위치: `notes/{과목 폴더}/figures/chNN/` (그림, `figures.json`). 노트에서 `figures/chNN/fig4-1.png`로 바로 가리킬 수 있게 노트 옆에 둔다. git 제외 (`.gitignore`의 `notes/*/figures/`).
- 점검 이미지: `.cache/work/{과목 폴더}/chNN-figures/` (작업 파일과 같은 곳).
- PNG는 300 DPI이고 PNG에 DPI를 적는다. note-pdf는 이 값으로 교재에 인쇄된 크기를 되살린다.
- 노트 형식 (`CLAUDE.md` "교재 그림은 모두 넣는다"): 그림이 보여 주는 개념을 설명한 문단 바로 뒤에 `![교재 그림 4-1](figures/ch04/fig4-1.png)`, 다음 줄에 `*교재 그림 4-1 — 제목 (PDF p.5)*`. 그림 속 기호가 노트와 다르면 시험 표기를 단다.
- `/chapter-note`: 1단계에서 도구 실행 → 점검 이미지 전부 확인 → manual.json으로 고치기 → 필수 그림을 `scope.md` "그림" 절에 적기. 2단계에서 그림을 마디에 배정. 3단계에서 넣고 파트 검증 에이전트가 그림도 확인. 4단계 처음에 `--check`로 누락·중복 점검.
- 손으로 고친 내용(`manual.json`)은 git에 올린다. 좌표와 id만 있어 교재 내용이 들어가지 않는다.

## 검증 결과

- **전 과목 54장, 경고 0건.** 필수 그림 660개(회로이론 150, 제어공학 62, 전기기기 128, 전기설비기술기준 52, 전기자기학 133, 전력공학 135), 후보(글만 든 표·표시 없는 표) 227개.
- **점검 3회.** 과목별 에이전트 6개가 점검 이미지를 모두 보고 문제를 모았다. 1차 약 130건 → 규칙 수정 → 2차 약 95건 → 규칙 수정 → 3차 약 45건. 3차에서 남은 것은 대부분 범례가 빠진 그림, 갈라진 그림, 본문 조각이 딸린 그림이었고, 그림이 아닌 것을 그림으로 본 경우는 회로이론 10장 p08-1 하나였다.
- **3차 잔여는 `manual.json`으로 고쳤다** (회로이론 1~3장은 노트를 다시 쓰지 않으므로 제외): 과목 6개 23장, merge 10건·rect 33건·exclude 1건·add 1건. 다시 실행해 경고 없이 모두 적용되었고, 고친 그림을 모두 열어 확인했다 (캡션 조각이 걸린 전기기기 3장 그림 3-3은 한 번 더 고침).
- **회로이론 4장 실제 실행**: `notes/circuit-theory/figures/ch04/`에 필수 6개, 경고 없음, 점검 이미지 정상. 임시 노트로 `--check`가 다 넣으면 「통과」(종료 0), 하나 빼면 빠진 그림을 알리고 「실패」(종료 1)함을 확인했다. note-pdf는 그림을 잘라 낸 영역 크기(±0.5pt)로 넣었고, 기존 3장 PDF도 그대로 만들어진다.
- 개인정보 검사: 잘라 낸 모든 영역에서 워터마크·응원 문구 검사 통과 (멈춘 챕터 없음). 그림·점검 이미지는 git 제외 폴더에만 생긴다.
