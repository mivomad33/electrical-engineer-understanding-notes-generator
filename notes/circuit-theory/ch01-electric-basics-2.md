## 저항을 직렬과 병렬로 이으면

[앞 파일](./ch01-electric-basics-1.md#회로-전체가-지키는-두-규칙-kcl과-kvl)에서 회로 전체가 지키는 두 규칙, 곧 접속점에서의 전하 보존(KCL)과 폐회로에서의 에너지 보존(KVL)을 세웠다. 이제 이 규칙을 저항 여러 개가 이어진 회로에 적용해 보자. 저항을 잇는 가장 기본적인 방법은 두 가지다.

- **직렬연결**: 저항을 한 줄로 차례차례 잇는다. 전류가 지나갈 길이 **하나**뿐이다.
- **병렬연결**: 저항들의 양 끝을 같은 두 점에 나란히 잇는다. 전류가 지나갈 길이 **여러 갈래**로 나뉜다.

어떤 연결이든 목표는 같다. 여러 저항을 전원 쪽에서 보았을 때 똑같은 효과를 내는 **저항 하나**로 바꾸는 것이다. 이 하나의 저항을 **합성저항**(등가저항)이라 하고 $R_T$로 적는다. 합성저항을 알면 옴의 법칙 하나로 전체 전류를 바로 구할 수 있다.

### 직렬연결: 전류가 같다

저항 $R_1$, $R_2$를 한 줄로 이어 전압 $V$를 걸었다고 하자. $R_1$과 $R_2$ 사이의 연결점에는 도선이 두 개뿐이다. 하나로 들어오고 하나로 나간다. KCL에 따라 들어온 전류와 나간 전류가 같으므로, $R_1$에 흐르는 전류와 $R_2$에 흐르는 전류는 같다.

$$I = I_1 = I_2$$

**직렬에서는 전류가 같다.** 이것이 직렬연결의 첫 번째 규칙이고, 앞 파일의 KVL 수치 예에서 확인했듯 KCL에서 바로 나온다.

다음으로 폐회로에 KVL을 적용하면, 전원 전압은 두 저항의 전압강하의 합과 같다. 각 전압강하에 옴의 법칙을 쓰고 공통인 $I$로 묶는다.

$$V = V_1 + V_2 = IR_1 + IR_2 = I(R_1 + R_2)$$

이 식을 옴의 법칙 $V = IR_T$와 나란히 놓으면, 두 저항은 전원 쪽에서 볼 때 저항 $R_1 + R_2$ 하나와 똑같이 행동한다. 그래서 직렬 합성저항은

$$R_T = R_1 + R_2\,[\Omega]$$

이고, 전체 전류는 $I = \dfrac{V}{R_T} = \dfrac{V}{R_1 + R_2}\,[\text{A}]$다.

저항이 $n$개여도 논리는 같다. 전류는 모두 같고 전압강하는 모두 더해지므로

$$R_T = R_1 + R_2 + \cdots + R_n\,[\Omega]$$

이다. 특히 같은 저항 $R$을 $n$개 직렬로 이으면 $R_T = nR$이다. [앞 파일](./ch01-electric-basics-1.md#흐름을-방해하는-것이-저항이다)에서 도선의 길이를 두 배로 하면 저항이 두 배가 된다고 한 것이 바로 이 경우다.

> **시험 표기** — 교재는 $n$개 직렬을 $R_T = R_1 + R_2 + R_3 + \cdots R_n$으로 적었다 (PDF p.8). $\cdots$와 $R_n$ 사이의 $+$가 빠진 오타다.

직렬에서 합성저항은 어느 저항보다도 크다. 방해 구간을 하나 더 붙이는 셈이기 때문이다.

### 병렬연결: 전압이 같다

이번에는 $R_1$, $R_2$의 양 끝을 같은 두 점에 이어 전압 $V$를 걸었다고 하자. 전원과 $R_1$은 하나의 폐회로를 이루고, 전원과 $R_2$도 또 하나의 폐회로를 이룬다. 각 폐회로에 KVL을 적용하면 $R_1$의 전압강하도 $V$, $R_2$의 전압강하도 $V$다. 두 저항의 양 끝이 같은 두 점이므로 그 두 점의 전위차가 곧 각 저항의 전압이라고 봐도 된다.

$$V = V_1 = V_2$$

**병렬에서는 전압이 같다.** 이것이 병렬연결의 규칙이고, KVL에서 나온다.

이번에는 전류가 갈라진다. 전류가 나뉘는 접속점에 KCL을 적용하면 전체 전류는 두 가지 전류의 합이다. 각 가지 전류에 옴의 법칙을 쓰고 공통인 $V$로 묶는다.

$$I = I_1 + I_2 = \frac{V}{R_1} + \frac{V}{R_2} = V\left(\frac{1}{R_1} + \frac{1}{R_2}\right)$$

이것을 옴의 법칙 $I = \dfrac{V}{R_T}$와 나란히 놓으면

$$\frac{1}{R_T} = \frac{1}{R_1} + \frac{1}{R_2}$$

이다. 저항의 역수가 컨덕턴스이므로, 이 식은 **병렬에서는 컨덕턴스가 더해진다**($G_T = G_1 + G_2$)는 뜻이다. 길이 하나 더 생기면 전기가 그만큼 더 잘 통한다. [앞 파일](./ch01-electric-basics-1.md#흐름을-방해하는-것이-저항이다)에서 단면적을 두 배로 하면 저항이 절반이 된다고 한 것이 이 경우다.

저항이 두 개일 때는 분모를 통분해 정리하면 계산하기 편한 꼴이 된다.

$$R_T = \frac{1}{\frac{1}{R_1} + \frac{1}{R_2}} = \frac{1}{\frac{R_1 + R_2}{R_1R_2}} = \frac{R_1R_2}{R_1 + R_2}\,[\Omega]$$

흔히 "합분의 곱"이라 부르는 꼴이다. 병렬 합성을 짧게 $R_1 \parallel R_2$로 적기도 한다. "$R_1$과 $R_2$를 병렬로 이은 합성저항"이라는 뜻이다. 이 합성저항을 쓰면 병렬 부분에 걸린 전압은 $V = R_T I = \dfrac{R_1R_2}{R_1 + R_2}I$로 전체 전류에서 바로 구할 수 있다.

> **헷갈림 주의** — "합분의 곱" $\frac{R_1R_2}{R_1 + R_2}$은 저항이 **두 개**일 때만 성립한다. 세 개를 $\frac{R_1R_2R_3}{R_1 + R_2 + R_3}$로 쓰면 틀린다 (단위부터 $[\Omega^2]$이 되어 맞지 않는다). 세 개 이상은 역수의 합을 쓰거나, 두 개씩 차례로 묶는다.

저항이 $n$개면

$$R_T = \frac{1}{\frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n}}\,[\Omega]$$

이고, 같은 저항 $R$을 $n$개 병렬로 이으면 컨덕턴스가 $n$배가 되므로 $R_T = \dfrac{R}{n}$이다.

병렬에서 합성저항은 어느 저항보다도 작다. 길을 하나 더 열어 주는 셈이기 때문이다. 아무리 큰 저항이라도 병렬로 하나 더 달면 전체 저항은 줄어든다.

두 연결을 나란히 놓으면 다음과 같다.

| | 직렬 | 병렬 |
|---|---|---|
| 같은 것 | 전류 (KCL에서) | 전압 (KVL에서) |
| 나뉘는 것 | 전압 $V = V_1 + V_2$ | 전류 $I = I_1 + I_2$ |
| 합성 | $R_T = R_1 + R_2$ | $\frac{1}{R_T} = \frac{1}{R_1} + \frac{1}{R_2}$, 2개면 $\frac{R_1R_2}{R_1 + R_2}$ |
| 같은 $R$ $n$개 | $nR$ | $\frac{R}{n}$ |
| 합성저항의 크기 | 가장 큰 저항보다 크다 | 가장 작은 저항보다 작다 |

### 직렬과 병렬이 섞인 회로

실제 문제에는 직렬과 병렬이 섞여 나온다. 푸는 원리는 간단하다. **안쪽부터 하나씩 묶어 저항 하나로 바꾸는 일을 반복한다.** 예를 들어 $R_1 = 1.8[\Omega]$에 이어서 $R_2 = 3[\Omega]$, $R_3 = 6[\Omega]$의 병렬 묶음이 직렬로 붙어 있고, 전체에 $19[\text{V}]$를 걸었다고 하자.

1. 병렬 묶음을 하나로: $\dfrac{3 \times 6}{3 + 6} = 2[\Omega]$
2. 이것과 $R_1$은 직렬: $R_T = 1.8 + 2 = 3.8[\Omega]$
3. 전체 전류: $I = \dfrac{19}{3.8} = 5[\text{A}]$

이 $5[\text{A}]$가 병렬 묶음에서 $R_2$와 $R_3$로 어떻게 나뉘는지는 다음 마디의 분류법칙으로 구한다.

거꾸로 생각하는 문제도 있다. 어떤 회로의 두 단자에 전압 $V$를 걸고 전류 $I$를 측정했다면, 회로 속이 어떻게 생겼든 두 단자에서 본 합성저항은 $R_T = \frac{V}{I}$다. 이 값을 회로 구조로 세운 합성저항 식과 같다고 놓으면 모르는 저항 값을 구할 수 있다. 회로 구조를 읽을 때는 **두 단자 사이에 전류가 갈 수 있는 길이 몇 갈래인지**를 본다. 예를 들어 같은 저항 $r$ 세 개를 삼각형으로 잇고 한 변의 양 끝을 단자로 쓰면, 단자 사이에는 저항 $r$ 하나를 지나는 길과 나머지 두 개를 지나는 길($r + r = 2r$, 직렬)이 있다. 두 길은 병렬이므로 합성저항은 $\frac{r \times 2r}{r + 2r} = \frac{2}{3}r$이다.

> **시험 표기** — 기출 해설은 합성저항을 $R_T$ 외에 $R_{th}$로도 쓴다 (PDF p.16). 이 문제에서는 $R_T$와 같은 뜻이다. ($R_{th}$는 원래 회로를 등가 전원과 저항 하나로 바꾸는 다른 개념에서 쓰는 기호라서, 테브난 정리를 다루는 챕터에서 그 뜻으로 다시 나온다.)

합성저항으로 전체 전류는 구했다. 그렇다면 그 전체 전압과 전체 전류는 각 저항에 얼마씩 돌아가는가?

## 직렬은 전압을 나누고 병렬은 전류를 나눈다

앞 마디의 표에서 보았듯 직렬에서는 전압이, 병렬에서는 전류가 나뉜다. 이제 "얼마씩" 나뉘는지를 식으로 구한다. 실제 회로 문제의 대부분은 전체를 합성저항으로 풀고, 이 두 법칙으로 다시 각 저항의 몫을 구하는 순서로 진행된다.

### 분압법칙: 직렬에서 전압 나누기

직렬에서는 모든 저항에 같은 전류가 흐르므로, 각 저항의 전압강하 $IR$은 **저항에 비례**한다. 저항이 큰 쪽이 전압을 더 많이 가져간다. 몇 대 몇으로 나뉘는지 식으로 써 보자. 전체 전류는 $I = \frac{V}{R_1 + R_2}$이므로

$$V_1 = IR_1 = \frac{R_1}{R_1 + R_2}V\,[\text{V}], \qquad V_2 = IR_2 = \frac{R_2}{R_1 + R_2}V\,[\text{V}]$$

이다. 전체 전압 $V$를 저항의 비 $R_1 : R_2$로 나눠 갖는다는 뜻이다. 이것을 **분압법칙**(전압의 분배)이라 한다. 분자에 **자기 저항**이 온다. 예를 들어 $10[\text{V}]$를 $2[\Omega]$과 $3[\Omega]$ 직렬에 걸면 $V_1 = \frac{2}{5} \times 10 = 4[\text{V}]$, $V_2 = \frac{3}{5} \times 10 = 6[\text{V}]$이고, 합은 KVL대로 $10[\text{V}]$다.

### 분류법칙: 병렬에서 전류 나누기

병렬에서는 모든 저항에 같은 전압이 걸리므로, 각 가지의 전류 $\frac{V}{R}$는 **저항에 반비례**한다. 저항이 작은 길로 전류가 더 많이 간다. 식으로 쓰려면 먼저 병렬 부분의 전압을 전체 전류로 나타내고(합성저항 × 전체 전류), 그것을 각 저항으로 나눈다.

$$I_1 = \frac{V}{R_1} = \frac{R_1R_2}{R_1 + R_2}I \times \frac{1}{R_1} = \frac{R_2}{R_1 + R_2}I\,[\text{A}]$$

$$I_2 = \frac{V}{R_2} = \frac{R_1R_2}{R_1 + R_2}I \times \frac{1}{R_2} = \frac{R_1}{R_1 + R_2}I\,[\text{A}]$$

이것을 **분류법칙**(전류의 분배)이라 한다. 분압법칙과 달리 분자에 **상대편 저항**이 온다. 이유는 이렇다. 상대편 $R_2$가 클수록 그쪽 길이 좁아지므로 전류가 내 쪽($R_1$)으로 더 많이 온다. 그래서 내 몫은 상대편 저항에 비례한다.

앞 절의 예에서 $5[\text{A}]$가 $3[\Omega]$과 $6[\Omega]$ 병렬로 들어가면, $3[\Omega]$ 쪽으로 $\frac{6}{3 + 6} \times 5 = \frac{10}{3}[\text{A}]$, $6[\Omega]$ 쪽으로 $\frac{3}{9} \times 5 = \frac{5}{3}[\text{A}]$가 흐른다. 작은 저항 쪽이 두 배 많이 가져가고, 합은 KCL대로 $5[\text{A}]$다.

> **헷갈림 주의** — 분압은 "자기 저항이 분자", 분류는 "상대 저항이 분자"다. 외우지 말고 이렇게 확인하면 된다. 컨덕턴스로 쓰면 분류법칙은 $I_1 = \frac{G_1}{G_1 + G_2}I$가 되어 분압법칙과 똑같은 모양이 된다. 직렬에서는 저항이 클수록, 병렬에서는 잘 통할수록(컨덕턴스가 클수록) 많이 가져간다. 실제로 $\frac{G_1}{G_1 + G_2}$의 분모·분자에 $R_1R_2$를 곱하면 $\frac{R_2}{R_2 + R_1}$이 된다.

지금까지는 전원이 언제나 정해진 전압 $V$를 낸다고 가정했다. 그런데 실제 전지에 큰 전류를 흘리면 전지 양 끝의 전압이 조금 떨어진다. 전지 안에서는 무슨 일이 일어나는가?

## 전지 자신에게도 저항이 있다

전지 안에서도 전하는 화학물질 속을 지나야 하므로 흐름이 방해를 받는다. 이 방해를 전지의 **내부저항** $r$이라 한다. 그래서 실제 전지는 "기전력 $E$인 이상적인 전원"과 "내부저항 $r$"이 **직렬로** 이어진 것으로 나타낸다. 이 둘을 점선 상자로 묶어 하나의 전지로 그리는 경우가 많다.

이 전지에 부하저항 $R$을 이으면, 전류는 $r$과 $R$을 차례로 지나므로 둘은 직렬이다. 합성저항은 $R + r$이고, 옴의 법칙으로

$$I = \frac{E}{R + r}\,[\text{A}]$$

이다. 이때 전지 양 끝(단자)에서 잰 전압은 기전력에서 내부저항의 전압강하를 뺀 $V = E - Ir$이다. 전류가 클수록 단자전압이 더 떨어지는 이유가 이것이다.

같은 전지를 여러 개 이어 쓰면 기전력과 내부저항은 어떻게 합쳐질까? 지금까지 세운 규칙을 그대로 적용하면 된다. 아래에서는 기전력 $E$와 내부저항 $r$이 **모두 같은** 전지 $n$개를 잇는다고 가정한다.

### 전지의 직렬연결

$n$개를 직렬로 이으면 폐회로를 따라 기전력 $n$개가 같은 방향으로 전위를 올리므로, KVL에 따라 기전력은 $nE$가 된다. 내부저항 $n$개도 한 줄로 이어지므로 직렬 합성저항 $nr$이 된다. 부하 $R$까지 포함하면

$$I = \frac{nE}{R + nr}\,[\text{A}]$$

이다. 직렬연결은 **전압을 높이고 싶을 때** 쓴다. 손전등에 전지를 한 줄로 넣는 이유다.

### 전지의 병렬연결

$n$개를 병렬로 이으면 모든 전지의 양 끝이 같은 두 점에 이어진다. 병렬에서는 전압이 같으므로 전체 기전력은 $E$ 그대로다. 대신 내부저항 $r$이 $n$개 병렬이 되어 $\frac{r}{n}$로 줄어든다. 따라서

$$I = \frac{E}{R + \frac{r}{n}}\,[\text{A}]$$

이다. 병렬연결은 전압은 그대로 두고 **더 큰 전류를 더 오래 흘리고 싶을 때** 쓴다. 내부저항이 $\frac{r}{n}$로 줄어 같은 부하에 더 큰 전류를 보낼 수 있고, 전체 전류를 $n$개 전지가 똑같이 나눠 맡으므로(각각 전체의 $\frac{1}{n}$) 전지 하나의 부담이 줄어 더 오래 쓸 수 있다.

> **헷갈림 주의** — 병렬연결에서 "같은 전지"라는 가정이 중요하다. 기전력이 다른 전지를 병렬로 이으면, 부하가 없어도 기전력이 큰 전지에서 작은 전지로 전류가 돌며 서로 충·방전한다. 위 식은 쓸 수 없다.

### 직렬과 병렬을 섞은 연결

전지를 $s$개씩 직렬로 묶어 한 조를 만들고, 그런 조를 $p$개 병렬로 이으면, 위 두 결과를 차례로 적용한다. 한 조의 기전력은 $sE$, 내부저항은 $sr$이다. 같은 조 $p$개를 병렬로 이으면 기전력은 $sE$ 그대로이고 내부저항은 $\frac{sr}{p}$이 된다.

$$I = \frac{sE}{R + \frac{sr}{p}}\,[\text{A}]$$

예를 들어 $E = 1.5[\text{V}]$, $r = 0.2[\Omega]$인 전지 4개를 2개씩 직렬로 묶어 2조를 병렬로 잇고 $R = 2.8[\Omega]$을 연결하면, 기전력 $2 \times 1.5 = 3[\text{V}]$, 내부저항 $\frac{2 \times 0.2}{2} = 0.2[\Omega]$이므로 $I = \frac{3}{2.8 + 0.2} = 1[\text{A}]$다. 기전력은 **직렬로 이은 개수만큼만** 늘고, 병렬로는 늘지 않는다는 점에 주의한다.

> **시험 표기** — 기출 해설은 전지의 합성 내부저항을 $R_i$로, 등가회로 그림에서는 $R_t$로, 부하저항을 $R_L$로 쓴다 (PDF p.16). 이 노트의 $r$(합성하면 $\frac{sr}{p}$)과 $R$에 해당한다.

전지는 전하를 밀어 올려 에너지를 주고, 부하는 그 에너지를 받아 쓴다. 그렇다면 부하는 1초에 얼마만큼의 에너지를 쓰는가?

## 전기가 하는 일의 양은 전력과 전력량이다

### 전력: 1초 동안 하는 일

저항에 전류가 흐르면 전하가 내놓은 에너지가 열이나 빛으로 바뀐다. 같은 에너지라도 짧은 시간에 쓰면 더 "센" 셈이므로, 전기가 **단위시간(1초) 동안 하는 일**을 **전력**(電力, power)이라 정의하고 $P$로 적는다. 단위는 와트 $[\text{W}] = [\text{J/s}]$다.

$$P = \frac{W}{t}\,[\text{W}]$$

이 정의에 지금까지 세운 관계를 차례로 넣어 보자. 먼저 전하 $Q$가 전압 $V$를 지나며 내놓는 에너지는 $W = VQ$다(전압의 정의). 그리고 $\frac{Q}{t}$는 전류의 정의다. 그래서

$$P = \frac{W}{t} = \frac{VQ}{t} = V \cdot \frac{Q}{t} = VI\,[\text{W}]$$

이다. **전력 = 전압 × 전류.** 1[C]당 내놓는 에너지(전압)에 1초에 지나가는 쿨롱 수(전류)를 곱하면 1초에 내놓는 에너지가 된다는, 단위로 봐도 자연스러운 결과다.

저항에서는 옴의 법칙으로 $V$나 $I$ 중 하나를 지울 수 있다. $V = IR$을 넣으면 $P = I \cdot IR = I^2R$, $I = \frac{V}{R}$을 넣으면 $P = V \cdot \frac{V}{R} = \frac{V^2}{R}$이다. 모아 쓰면

$$P = \frac{W}{t} = \frac{VQ}{t} = VI = I^2R = \frac{V^2}{R}\,[\text{W}]$$

이다. 세 꼴은 같은 값이지만 쓰임이 다르다. **직렬**처럼 전류가 같은 경우에는 $I^2R$로 보면 저항이 큰 쪽이 전력을 더 많이 쓴다. **병렬**처럼 전압이 같은 경우에는 $\frac{V^2}{R}$로 보면 저항이 **작은** 쪽이 전력을 더 많이 쓴다. 가정의 전기기구는 모두 같은 전압에 병렬로 연결되므로, 전력이 큰 기구일수록 저항이 작다.

$\frac{V^2}{R}$ 꼴에서 중요한 성질이 하나 더 나온다. 저항이 일정하면 **전력은 전압의 제곱에 비례**한다($P \propto V^2$). 예를 들어 정격전압의 $90[\%]$만 걸면 전력은 $0.9^2 = 0.81$, 곧 $81[\%]$로 줄어든다. 전압이 줄면 전류도 같은 비율로 줄기 때문에 두 번 줄어드는 것이다.

### 전력량: 일정 시간 동안 한 일의 총량

전력이 "1초당 일"이라면, 일정 시간 $t$ 동안 한 일의 총량은 전력에 시간을 곱한 것이다. 이것을 **전력량**이라 한다.

$$W = Pt = VIt = I^2Rt = \frac{V^2}{R}t\,[\text{J}] = [\text{W}\cdot\text{s}]$$

$t$를 초로 넣으면 단위는 $[\text{J}] = [\text{W}\cdot\text{s}]$다. 그런데 줄은 일상에서 쓰기에 너무 작은 단위라서, 실무와 전기요금에서는 $t$를 시간 $[\text{h}]$로 넣어 $[\text{Wh}]$나 $[\text{kWh}]$를 쓴다. 킬로($\text{k}$)는 $10^3$이다. 둘 사이 환산은 1시간이 3600초라는 데서 나온다.

$$1\,[\text{kWh}] = 10^3\,[\text{Wh}] = 10^3 \times 3600\,[\text{W}\cdot\text{s}] = 3.6 \times 10^6\,[\text{J}]$$

> **헷갈림 주의** — 같은 글자 $W$가 두 가지로 쓰인다. 기울임꼴 $W$는 에너지(전력량)라는 **물리량**이고, 대괄호 안의 $[\text{W}]$는 전력의 **단위**(와트)다. "$W[\text{J}]$"는 "에너지 $W$, 단위 줄"로 읽는다.

> **시험 표기** — 교재는 초를 $[\text{sec}]$로 적어 $[\text{J} = \text{W}\cdot\text{sec}]$로 쓴다 (PDF p.12).

### 줄의 법칙: 전력은 열이 된다

저항에서 소비된 전력량은 어디로 가는가? [앞 파일](./ch01-electric-basics-1.md#흐름을-방해하는-것이-저항이다)에서 본 대로 자유전자가 원자와 부딪히며 에너지를 넘겨주므로, 결국 **열**이 된다. 저항에 전류 $I$가 $t$초 동안 흐를 때 발생하는 열은 그동안 소비된 전력량 $I^2Rt$와 같다. 이것을 **줄의 법칙**이라 하고, 이렇게 생기는 열을 **줄열**이라 한다. 전기난로, 전기다리미, 퓨즈가 모두 이 원리로 동작한다.

$$H = I^2Rt\,[\text{J}]$$

열량은 전통적으로 칼로리 $[\text{cal}]$ 단위로 잰다. $1[\text{cal}]$은 물 $1[\text{g}]$의 온도를 $1[^\circ\text{C}]$ 올리는 데 필요한 열량으로 **정의**한 단위다. 그렇다면 $1[\text{J}]$의 일이 몇 칼로리의 열이 되는가? 칼로리는 물의 온도로, 줄은 힘과 거리로 따로 정의한 단위이므로, 둘의 관계는 계산으로 나오지 않고 **실험으로 측정**해야 한다. 1840년대에 줄(James Joule)이 일을 열로 바꾸는 실험으로 이 관계를 처음 재어 열과 일이 같은 에너지임을 보였고, 이후 더 정밀한 측정을 바탕으로 다음 값이 정해졌다.

$$1\,[\text{J}] = 0.2388\,[\text{cal}] \fallingdotseq 0.24\,[\text{cal}]$$

거꾸로 쓰면 $1[\text{cal}] \fallingdotseq 4.186[\text{J}]$이다. (지금은 반대로 칼로리를 이 측정 결과에 맞춰 줄로 정의해 쓴다.) 그래서 줄의 법칙을 칼로리로 쓰면

$$H = 0.24\,I^2Rt\,[\text{cal}]$$

이 된다. 일반적으로 전력량 $W[\text{J}]$가 모두 열로 바뀌면 $H = 0.24W\,[\text{cal}]$이다.

$[\text{kWh}]$와 $[\text{kcal}]$ 사이의 환산은 위의 두 값에서 계산으로 나온다.

$$1\,[\text{kWh}] = 3.6 \times 10^6\,[\text{J}] \times 0.2388\,[\text{cal/J}] \fallingdotseq 860 \times 10^3\,[\text{cal}] = 860\,[\text{kcal}]$$

($0.24$로 어림한 값을 쓰면 $864[\text{kcal}]$이 되므로, 860은 더 정확한 $0.2388$에서 나온 값이다.) 그래서 전력량 $W$를 $[\text{kWh}]$로 넣으면 $H = 860W\,[\text{kcal}]$이다.

> **시험 표기** — 교재는 이 두 환산을 "전력[W] ↔ 열[cal] 환산 공식"이라는 TIP으로 정리한다: ① $H = 0.24W$ ($H[\text{cal}]$, $W[\text{W}\cdot\text{sec} = \text{J}]$일 때), ② $H = 860W$ ($H[\text{kcal}]$, $W[\text{kW}\cdot\text{h}]$일 때) (PDF p.12). 두 식의 $W$는 단위가 다르다는 점에 주의한다. 또 교재는 "줄의 법칙" 절에 법칙 자체($H = I^2Rt$)는 적지 않고 환산값만 나열한다.

이제 회로의 전압·전류·전력을 모두 계산할 수 있다. 그런데 계산한 값이 맞는지 확인하려면 실제로 **재야** 한다. 전압계와 전류계는 회로에 어떻게 연결해야 하고, 계기의 눈금보다 큰 값은 어떻게 잴까?

## 계기의 측정 범위를 넓히는 배율기와 분류기

### 전압계는 병렬로, 전류계는 직렬로

**전압계**는 두 점 사이의 전압을 잰다. 병렬로 이은 소자들은 전압이 같으므로, 재려는 소자에 전압계를 **병렬로** 이으면 전압계에 그 소자와 같은 전압이 걸린다. 그런데 전압계 자체로 전류가 많이 새면 원래 회로가 바뀐다. 그래서 전압계는 **내부저항 $R_v$가 매우 크게** 만든다. 이상적인 전압계는 내부저항이 무한대여서 전류를 전혀 빼앗지 않는다.

**전류계**는 흐르는 전류를 잰다. 직렬로 이은 소자들은 전류가 같으므로, 재려는 전류가 지나가는 길을 끊고 그 사이에 전류계를 **직렬로** 끼우면 그 전류가 그대로 전류계를 지나간다. 이번에는 전류계가 전압을 많이 잡아먹으면 회로가 바뀐다. 그래서 전류계는 **내부저항 $R_a$가 매우 작게** 만든다. 이상적인 전류계는 내부저항이 0이다.

> **헷갈림 주의** — 전류계를 실수로 병렬로 이으면, 내부저항이 아주 작아서 그 길로 매우 큰 전류가 몰려 전류계가 타 버릴 수 있다. 전압계를 직렬로 이으면, 내부저항이 아주 커서 회로 전류가 거의 0이 되어 회로가 사실상 끊긴다. 연결 방법은 계기의 내부저항 크기와 한 묶음으로 기억한다.

각 계기에는 잴 수 있는 최댓값이 정해져 있다. 그보다 큰 전압이나 전류를 재려면 저항을 하나 덧붙여, 측정할 양의 **일부만** 계기에 가도록 하면 된다. 일부만 가게 하는 방법은 이미 알고 있다. 전압은 직렬로 나누고(분압), 전류는 병렬로 나눈다(분류).

### 배율기: 전압계에 직렬로 큰 저항

전압계에 저항 $R_m$을 **직렬로** 이으면 측정할 전압 $V$가 $R_m$과 전압계로 나뉜다. 이 저항을 **배율기**라 한다. 전압계가 감당할 수 있는 만큼만 전압계에 걸리고 나머지는 $R_m$이 맡는다.

측정할 전압 $V$가 전압계에 걸리는 전압 $V_v$의 몇 배인지를 **배율** $m$이라 하자.

$$m = \frac{V}{V_v}$$

전압계와 배율기는 직렬이므로 같은 전류 $I$가 흐른다. 전압계에 걸리는 전압은 $V_v = IR_v$이고, 전체 전압은 $V = I(R_v + R_m)$이다. 둘을 나누면 $I$가 지워진다.

$$m = \frac{V}{V_v} = \frac{I(R_v + R_m)}{IR_v} = 1 + \frac{R_m}{R_v}$$

이것을 $R_m$에 대해 풀면 배율기 저항이 나온다.

$$\begin{aligned}
m - 1 &= \frac{R_m}{R_v} \\
R_m &= (m - 1)R_v\,[\Omega]
\end{aligned}$$

의미는 이렇다. 측정 범위를 $m$배로 늘리려면 전체 전압 중 전압계 몫이 $\frac{1}{m}$이어야 하고, 나머지 $\frac{m-1}{m}$을 배율기가 맡아야 한다. 직렬에서는 전압이 저항에 비례하므로, 배율기 저항은 전압계 내부저항의 $(m-1)$배여야 한다. 전압계의 $R_v$가 원래 크므로 배율기는 **큰** 저항이다. 예를 들어 최대 $150[\text{V}]$, 내부저항 $15[\text{k}\Omega]$인 전압계로 $600[\text{V}]$까지 재려면 $m = 4$이므로 $R_m = 3 \times 15 = 45[\text{k}\Omega]$을 직렬로 단다.

> **시험 표기** — 교재 그림 1-19는 배율기 전압을 $V_m$, 전압계에 걸리는 전압과 전체 측정 전압을 둘 다 $V$로 적고, 배율 $m$의 정의식은 따로 적지 않는다 (PDF p.14). 이 노트는 둘을 구별하려고 전압계 전압을 $V_v$로 쓴다. 교재 TIP은 배율기를 "배율 저항기($R_m$)"라 부르며, 전압계는 회로와 병렬로, 배율 저항기는 전압계와 직렬로 연결한다고 정리한다.

### 분류기: 전류계에 병렬로 작은 저항

전류계에 저항 $R_s$를 **병렬로** 이으면 측정할 전류 $I$가 $R_s$ 쪽($I_s$)과 전류계 쪽($I_a$)으로 나뉜다. 이 저항을 **분류기**라 한다. 전류계가 감당할 수 있는 만큼만 전류계로 가고 나머지는 분류기로 돌아간다.

측정할 전류 $I$가 전류계에 흐르는 전류 $I_a$의 몇 배인지를 **배율** $n$이라 하자.

$$n = \frac{I}{I_a}$$

전류계와 분류기는 병렬이므로 전압이 같다. 곧 $I_aR_a = I_sR_s$이고, 여기서 $I_s = \frac{R_a}{R_s}I_a$다. KCL에 따라 전체 전류는 $I = I_a + I_s$이므로

$$n = \frac{I}{I_a} = \frac{I_a + \frac{R_a}{R_s}I_a}{I_a} = 1 + \frac{R_a}{R_s}$$

이다. 이것을 $R_s$에 대해 푼다.

$$\begin{aligned}
n - 1 &= \frac{R_a}{R_s} \\
R_s &= \frac{R_a}{n - 1}\,[\Omega]
\end{aligned}$$

의미는 이렇다. 범위를 $n$배로 늘리려면 전체 전류 중 $\frac{1}{n}$만 전류계로 가고 나머지 $\frac{n-1}{n}$은 분류기로 가야 한다. 병렬에서는 전류가 저항에 반비례하므로, 분류기는 전류계보다 $(n-1)$배 **잘 통해야**, 곧 저항이 $\frac{1}{n-1}$배여야 한다. 전류계의 $R_a$가 원래 작으므로 분류기는 더 **작은** 저항이다. 예를 들어 내부저항 $0.9[\Omega]$인 전류계의 범위를 $10$배로 넓히려면 $R_s = \frac{0.9}{9} = 0.1[\Omega]$을 병렬로 단다.

배율기와 분류기의 결과는 모양이 짝을 이룬다. 배율기는 $m = 1 + \frac{R_m}{R_v}$, 분류기는 $n = 1 + \frac{R_a}{R_s}$다. 덧붙인 저항이 직렬이면 분자에, 병렬이면 분모에 온다.

> **헷갈림 주의** — $n$은 이 챕터에서 두 가지 뜻으로 쓰인다. 저항이나 전지를 이을 때는 "개수"이고, 여기 분류기에서는 "배율"이다. 교재와 시험이 둘 다 $n$을 쓰므로 이 노트도 따르되, 분류기 공식에서의 $n$은 배율이라는 점을 기억한다.

> **시험 표기** — 교재 본문은 분류기를 $R_s = \frac{R_a}{n-1}$로 쓰고 TIP에서 분류기를 "분류 저항기($R_s$)"라 부르며, 전류계는 회로와 직렬로, 분류 저항기는 전류계와 병렬로 연결한다고 정리한다 (PDF p.14). 그런데 기출 해설은 분류기의 배율을 $m = 1 + \frac{R_m}{R_s}$로 써서, 배율기에 쓰던 $m$을 배율로, $R_m$을 전류계 내부저항으로 쓴다 (PDF p.17). 이 노트의 $n = 1 + \frac{R_a}{R_s}$와 같은 식이다. 기호만 보고 배율기 공식으로 착각하지 않도록, 분류기는 "병렬 저항 $R_s$가 분모에 온다"로 알아본다.

전류계 가운데에는 아주 작은 전류도 감지하고, 바늘이 0을 가운데에 두고 전류 방향에 따라 좌우로 움직이는 것이 있다. 이것을 **검류계**(galvanometer, G)라 한다. 검류계는 전류의 크기를 재기보다 "전류가 흐르는가, 흐르지 않는가"를 확인하는 데 쓴다. 전류가 흐르지 않는다는 사실로 무엇을 알 수 있을까?

## 휘스톤 브리지는 전위가 같은 두 점을 찾는다

[앞 파일](./ch01-electric-basics-1.md#전하를-미는-것이-전압이다)에서 보았듯, 전류를 움직이는 것은 전위차다. 거꾸로 말하면 **두 점의 전위가 같으면 두 점 사이를 저항이나 도선으로 이어도 전류가 흐르지 않는다.** 높이가 같은 두 물통을 관으로 이어도 물이 흐르지 않는 것과 같다. 이 원리로 만든 회로가 **휘스톤 브리지**다.

회로는 이렇게 생겼다. 네 점 a, b, c, d가 마름모 꼴로 놓이고, 네 변에 저항이 하나씩 있다.

```
            c
      R1  /   \  R4
         /  G  \
    a ●    |    ● b
         \  |  /
      R2  \   /  R3
            d
   (a와 b 사이에 전원 V, c와 d 사이에 검류계 G)
```

- a–c 사이 $R_1$, c–b 사이 $R_4$ (위쪽 길)
- a–d 사이 $R_2$, d–b 사이 $R_3$ (아래쪽 길)
- a–b 사이에 전원 $V$, 가운데 c–d 사이에 검류계 G

전류는 a에서 위쪽 길(a→c→b)과 아래쪽 길(a→d→b)로 나뉘어 b로 간다. 가운데 c–d를 "다리(bridge)"처럼 가로지르는 검류계가 붙어 있어서 브리지라 부른다.

### 평형 조건 유도

검류계에 전류가 흐르지 않는 상태를 브리지가 **평형**이라 한다. 이때 저항들 사이에 어떤 관계가 있어야 하는지 구해 보자.

1. **가운데 전류가 0이면 위쪽·아래쪽 길이 각각 직렬이다.** 검류계로 전류가 빠지지 않으므로 점 c에서 KCL에 따라 $R_1$의 전류와 $R_4$의 전류가 같다. 이것을 $I_1$이라 하자. 마찬가지로 점 d에서 $R_2$와 $R_3$의 전류가 같고, 이것을 $I_2$라 하자.
2. **c와 d의 전위가 같다.** 검류계에 전류가 흐르지 않는다는 것은 $V_c = V_d$라는 뜻이다. 그러면 a에서 c까지 떨어진 전위와 a에서 d까지 떨어진 전위가 같다. 각각 $R_1$, $R_2$의 전압강하이므로

   $$I_1R_1 = I_2R_2 \qquad \cdots (1)$$

3. **c에서 b까지와 d에서 b까지도 같다.** 같은 이유로 $R_4$와 $R_3$의 전압강하가 같다.

   $$I_1R_4 = I_2R_3 \qquad \cdots (2)$$

4. **전류를 지운다.** 우리는 전류와 상관없이 저항만의 조건을 원하므로, (1)을 (2)로 나눠 $I_1$, $I_2$를 지운다.

   $$\frac{I_1R_1}{I_1R_4} = \frac{I_2R_2}{I_2R_3} \;\Rightarrow\; \frac{R_1}{R_4} = \frac{R_2}{R_3}$$

5. 양변에 $R_3R_4$를 곱하면 평형 조건이 나온다.

   $$R_1R_3 = R_2R_4$$

그림에서 $R_1$과 $R_3$, $R_2$와 $R_4$는 마름모의 **마주 보는 변**이다. 그래서 평형 조건은 "**마주 보는 변의 저항끼리 곱한 값이 같다**"로 기억한다. 식의 뜻은 단계 4의 꼴 $\frac{R_1}{R_4} = \frac{R_2}{R_3}$이 더 잘 보여 준다. 위쪽 길과 아래쪽 길이 전압을 **같은 비율로** 나누면(분압), 중간 지점 c와 d의 전위가 같아진다는 것이다. 전원 전압 $V$는 식에 나오지 않는다. 평형은 전압 크기와 상관없이 저항의 비로만 정해진다.

이 원리는 모르는 저항을 정밀하게 재는 데 쓴다. 예를 들어 $R_1$이 모르는 저항이면, 나머지 저항을 조절해 검류계 바늘이 0이 되게 한 뒤 $R_1 = \frac{R_2R_4}{R_3}$로 계산한다. 검류계는 전류의 크기를 정확히 읽을 필요 없이 "0인가"만 보면 되므로, 아주 정밀하게 잴 수 있다.

### 평형 브리지의 가운데 저항은 없애도 된다

평형 조건은 계산 문제에서 강력한 지름길이 된다. c–d 사이에 검류계 대신 저항이 있다고 하자. 먼저 그 저항을 떼어 낸 회로를 생각하면, 위쪽 길과 아래쪽 길은 각각 단순한 직렬 길이다. 분압법칙에 따라 a에서 c까지 떨어지는 전위는 $\frac{R_1}{R_1 + R_4}V$, a에서 d까지는 $\frac{R_2}{R_2 + R_3}V$다. 평형 조건 $\frac{R_1}{R_4} = \frac{R_2}{R_3}$이 성립하면 두 비율이 같으므로($\frac{R_1}{R_1 + R_4} = \frac{1}{1 + R_4/R_1}$이고 $\frac{R_2}{R_2+R_3} = \frac{1}{1 + R_3/R_2}$인데 $\frac{R_4}{R_1} = \frac{R_3}{R_2}$), c와 d의 전위가 같다. 이제 떼어 냈던 저항을 다시 이어도 그 양 끝의 전위차가 0이므로 전류가 흐르지 않고, 따라서 나머지 회로의 전류와 전압도 바뀌지 않는다. 곧 평형일 때 가운데 저항은 **떼어 내도(개방) 회로가 그대로다.** 전위가 같은 두 점을 도선으로 이어도(단락) 마찬가지로 아무것도 바뀌지 않는다.

그래서 평형 브리지의 합성저항은 가운데를 떼어 내고 "위쪽 길과 아래쪽 길의 병렬"로 계산하면 된다. a와 b 두 단자 사이에서 본 합성저항을 $R_{ab}$로 적으면

$$R_{ab} = (R_1 + R_4) \parallel (R_2 + R_3) = \frac{(R_1 + R_4)(R_2 + R_3)}{(R_1 + R_4) + (R_2 + R_3)}$$

예를 들어 $R_1 = 2[\Omega]$, $R_4 = 4[\Omega]$, $R_2 = 1[\Omega]$, $R_3 = 2[\Omega]$이고 가운데에 $5[\Omega]$이 있다고 하자. $R_1R_3 = 4$, $R_2R_4 = 4$로 평형이므로 가운데 $5[\Omega]$은 무시한다. 위쪽 길 $6[\Omega]$, 아래쪽 길 $3[\Omega]$의 병렬이므로 $R_{ab} = \frac{6 \times 3}{6 + 3} = 2[\Omega]$이다. 가운데를 단락시켜 계산해도 $(2 \parallel 1) + (4 \parallel 2) = \frac{2}{3} + \frac{4}{3} = 2[\Omega]$으로 같다. 두 방법의 답이 같다는 것이 가운데 소자가 정말로 아무 역할을 하지 않는다는 확인이다.

> **헷갈림 주의** — 가운데 저항을 없앨 수 있는 것은 **평형일 때만**이다. 평형이 아니면 c와 d 사이에 전위차가 있어 가운데로 전류가 흐르고, 이때는 직렬·병렬만으로는 합성저항을 구할 수 없다. 문제에서 가운데가 있는 마름모 회로가 나오면 먼저 마주 보는 변의 곱이 같은지부터 확인한다.

> **시험 표기** — 교재는 평형 조건 $R_1R_3 = R_2R_4$를 유도 없이 결과만 적는다 (PDF p.13). 기출 해설도 평형 브리지의 가운데 저항을 이유를 밝히지 않고 지운 뒤 위쪽·아래쪽 길의 병렬로 계산한다 (PDF p.17).

---

여기까지 오면 처음의 큰 질문, "전기는 회로 안에서 어떻게 흐르고, 그 흐름은 어떤 규칙을 따르나?"에 답할 수 있다. 회로 안에서 흐르는 것은 전하이고, 그 흐름의 세기가 전류다. 전하를 미는 것은 전위차, 곧 전압이고, 흐름을 방해하는 것이 저항이다. 세 양은 저항 하나에서 옴의 법칙 $V = IR$로 묶인다. 회로 전체에서는 접속점마다 전하가 보존되고(KCL), 폐회로마다 에너지가 보존된다(KVL). 이 세 규칙에서 직렬·병렬의 합성저항, 분압과 분류, 전지의 연결, 전력과 열이 모두 나왔고, 배율기·분류기와 휘스톤 브리지도 같은 규칙을 응용한 장치였다. [2장(정현파 교류)](./ch02-sinusoidal-ac-1.md)부터는 전압과 전류가 시간에 따라 변하는 교류를 다룬다. 그때도 KCL과 KVL은 순간순간 그대로 성립하므로, 이 챕터에서 세운 규칙이 계속 출발점이 된다.

# 부록

## 정리 — 이해하고 기억할 것

**회로와 기본 물리량**
- 전기회로는 끊긴 데 없이 한 바퀴 이어진 닫힌 길이다. 한 곳이라도 끊기면 회로 전체에서 전류가 멈춘다. → [본문](./ch01-electric-basics-1.md#전기회로는-닫힌-길이다)
- 회로 요소: 전원(에너지 공급), 부하(에너지 소비), 도선·스위치. 회로도에서 부하는 저항으로 그린다. → [본문](./ch01-electric-basics-1.md#전기회로는-닫힌-길이다)
- 전하는 물체가 띠는 전기적 성질·실체이고, 전하량 $Q$의 단위는 $[\text{C}]$다. 같은 종류는 밀고 다른 종류는 당긴다. → [본문](./ch01-electric-basics-1.md#전기의-정체는-전하다)
- 전자의 전하량 $e = -1.602 \times 10^{-19}[\text{C}]$ (측정값), $1[\text{C}] \fallingdotseq 6.24 \times 10^{18}$개 (계산값). → [본문](./ch01-electric-basics-1.md#전기의-정체는-전하다)
- 금속에서 움직이는 전하는 자유전자다. → [본문](./ch01-electric-basics-1.md#전기의-정체는-전하다)
- 전류의 정의 $I = \frac{Q}{t}\,[\text{A} = \text{C/s}]$, $Q = It$. 변하는 전류는 $i = \frac{dq}{dt}$, $q = \int i\,dt$. → [본문](./ch01-electric-basics-1.md#전하가-움직이면-전류다)
- 전류 방향 관례: 전원 바깥에서 (+)극 → (−)극. 실제 전자는 반대로 움직인다. 관례가 남은 이유는 계산 결과가 같기 때문이다. → [본문](./ch01-electric-basics-1.md#전하가-움직이면-전류다)
- 직류는 방향이 일정하고, 교류는 크기와 방향이 주기적으로 바뀐다. → [본문](./ch01-electric-basics-1.md#전하가-움직이면-전류다)
- 전위는 전하 1[C]당 위치에너지(기준점 0[V] 필요)이고, 전압은 두 점의 전위차다. → [본문](./ch01-electric-basics-1.md#전하를-미는-것이-전압이다)
- 전압의 정의 $V = \frac{W}{Q}\,[\text{V} = \text{J/C}]$, $W = QV$. 변하면 $v = \frac{dw}{dq}$, $w = \int v\,dq$. → [본문](./ch01-electric-basics-1.md#전하를-미는-것이-전압이다)
- 기전력 $E$는 전원이 전하를 (−)극에서 (+)극으로 밀어 올리는 능력이다. 단위는 [V]. → [본문](./ch01-electric-basics-1.md#전하를-미는-것이-전압이다)
- 회로 기호: 전류원(원 안에 화살표) → [본문](./ch01-electric-basics-1.md#전하가-움직이면-전류다), 전지(긴 줄이 +)·직류 전원(원 안에 ±)·교류 전원(원 안에 ~) → [본문](./ch01-electric-basics-1.md#전하를-미는-것이-전압이다)
- 저항 $R = \rho\frac{l}{A}\,[\Omega]$: 길이에 비례하고 단면적에 반비례한다. $\rho$는 물질 고유의 값 $[\Omega\cdot\text{m}]$. 단면적은 $[\text{m}^2]$로 넣는다($1[\text{mm}^2] = 10^{-6}[\text{m}^2]$). → [본문](./ch01-electric-basics-1.md#흐름을-방해하는-것이-저항이다)
- 컨덕턴스 $G = \frac{1}{R}\,[\mho]$. → [본문](./ch01-electric-basics-1.md#흐름을-방해하는-것이-저항이다)
- 물 비유: 전압 = 수위 차, 전류 = 물의 흐름, 저항 = 좁은 관. 한계: 실제로는 펌프가 있는 순환 수로다. → [본문](./ch01-electric-basics-1.md#흐름을-방해하는-것이-저항이다)

**회로의 법칙**
- 옴의 법칙 $V = IR$, $I = \frac{V}{R}$, $R = \frac{V}{I}$. 핵심은 $\frac{V}{I}$가 일정하다는 실험 사실이다. $1[\Omega] = 1[\text{V/A}]$. → [본문](./ch01-electric-basics-1.md#옴의-법칙은-세-양을-하나로-묶는다)
- 저항에 전류 $I$가 흐르면 양 끝에 전압강하 $IR$이 생긴다. → [본문](./ch01-electric-basics-1.md#옴의-법칙은-세-양을-하나로-묶는다)
- KCL(전하 보존): 접속점에서 들어오는 전류의 합 = 나가는 전류의 합. 곧 대수합 = 0. → [본문](./ch01-electric-basics-1.md#회로-전체가-지키는-두-규칙-kcl과-kvl)
- 전류 방향은 임의로 가정해 풀어도 된다. 답이 음수면 실제 방향이 반대다. → [본문](./ch01-electric-basics-1.md#회로-전체가-지키는-두-규칙-kcl과-kvl)
- KVL(에너지 보존): 폐회로에서 기전력의 합 = 전압강하의 합. 도는 방향으로 전원을 (+)→(−)로 지나면 −, 전류와 반대 방향으로 저항을 지나면 그 전압강하도 −. → [본문](./ch01-electric-basics-1.md#회로-전체가-지키는-두-규칙-kcl과-kvl)
- 기전력(전위 상승, 에너지를 줌)과 전압강하(전위 하강, 에너지를 내놓음)는 단위는 같지만 역할이 반대다. → [본문](./ch01-electric-basics-1.md#회로-전체가-지키는-두-규칙-kcl과-kvl)

**저항과 전지의 연결**
- 직렬: 전류가 같다(KCL). $R_T = R_1 + R_2 + \cdots + R_n$, 같은 $R$ $n$개는 $nR$. → [본문](#저항을-직렬과-병렬로-이으면)
- 병렬: 전압이 같다(KVL). $\frac{1}{R_T} = \sum \frac{1}{R_k}$ (컨덕턴스가 더해진다), 2개면 $\frac{R_1R_2}{R_1 + R_2}$, 같은 $R$ $n$개는 $\frac{R}{n}$. → [본문](#저항을-직렬과-병렬로-이으면)
- "합분의 곱"은 2개일 때만 성립한다. → [본문](#저항을-직렬과-병렬로-이으면)
- 직렬 합성저항은 가장 큰 저항보다 크고, 병렬 합성저항은 가장 작은 저항보다 작다. → [본문](#저항을-직렬과-병렬로-이으면)
- 혼합회로는 안쪽부터 묶어 합성저항 → 전체 전류 → 분압·분류 순으로 푼다. 측정한 $\frac{V}{I}$가 곧 단자 사이 합성저항이다. → [본문](#저항을-직렬과-병렬로-이으면)
- 분압: $V_1 = \frac{R_1}{R_1 + R_2}V$ (자기 저항이 분자, 저항에 비례). → [본문](#직렬은-전압을-나누고-병렬은-전류를-나눈다)
- 분류: $I_1 = \frac{R_2}{R_1 + R_2}I$ (상대 저항이 분자, 저항에 반비례). → [본문](#직렬은-전압을-나누고-병렬은-전류를-나눈다)
- 실제 전지 = 기전력 $E$ + 내부저항 $r$ 직렬. $I = \frac{E}{R + r}$, 단자전압 $V = E - Ir$. → [본문](#전지-자신에게도-저항이-있다)
- 같은 전지 $n$개 직렬: $nE$, $nr$, $I = \frac{nE}{R + nr}$. 병렬: $E$, $\frac{r}{n}$, $I = \frac{E}{R + \frac{r}{n}}$. → [본문](#전지-자신에게도-저항이-있다)
- 직렬연결은 전압을 높이려고, 병렬연결은 더 큰 전류를 더 오래 흘리려고 쓴다. 병렬연결은 같은 전지일 때만 쓴다. → [본문](#전지-자신에게도-저항이-있다)
- $s$개 직렬 × $p$조 병렬: $I = \frac{sE}{R + \frac{sr}{p}}$. 기전력은 직렬 개수만큼만 는다. → [본문](#전지-자신에게도-저항이-있다)

**전력과 열**
- 전력 $P = \frac{W}{t} = VI = I^2R = \frac{V^2}{R}\,[\text{W} = \text{J/s}]$. 직렬(전류 같음)이면 큰 저항이, 병렬(전압 같음)이면 작은 저항이 전력을 더 쓴다. → [본문](#전기가-하는-일의-양은-전력과-전력량이다)
- $R$이 일정하면 $P \propto V^2$. → [본문](#전기가-하는-일의-양은-전력과-전력량이다)
- 전력량 $W = Pt\,[\text{J} = \text{W}\cdot\text{s}]$, $1[\text{kWh}] = 3.6 \times 10^6[\text{J}]$. → [본문](#전기가-하는-일의-양은-전력과-전력량이다)
- 줄의 법칙: 저항에서 나는 열 $H = I^2Rt\,[\text{J}] = 0.24I^2Rt\,[\text{cal}]$. → [본문](#전기가-하는-일의-양은-전력과-전력량이다)
- $1[\text{cal}]$ = 물 1[g]을 1[℃] 올리는 열량(정의), $1[\text{J}] = 0.2388 \fallingdotseq 0.24[\text{cal}]$(측정에 근거한 값), $1[\text{kWh}] \fallingdotseq 860[\text{kcal}]$(계산값). $H = 0.24W$ ($W$[J]), $H = 860W$ ($W$[kWh]). → [본문](#전기가-하는-일의-양은-전력과-전력량이다)

**측정 장치**
- 전압계는 병렬로 연결하고 내부저항이 크다. 전류계는 직렬로 연결하고 내부저항이 작다. → [본문](#계기의-측정-범위를-넓히는-배율기와-분류기)
- 배율기: 전압계에 직렬로 큰 저항. $m = 1 + \frac{R_m}{R_v}$, $R_m = (m - 1)R_v$ (분압 원리). → [본문](#계기의-측정-범위를-넓히는-배율기와-분류기)
- 분류기: 전류계에 병렬로 작은 저항. $n = 1 + \frac{R_a}{R_s}$, $R_s = \frac{R_a}{n - 1}$ (분류 원리). 여기서 $n$은 개수가 아니라 배율이다. → [본문](#계기의-측정-범위를-넓히는-배율기와-분류기)
- 짝 대응: 덧붙인 저항이 직렬(배율기)이면 분자, 병렬(분류기)이면 분모에 온다. → [본문](#계기의-측정-범위를-넓히는-배율기와-분류기)
- 검류계(G)는 미소 전류의 유무와 방향을 확인한다. → [본문](#계기의-측정-범위를-넓히는-배율기와-분류기)
- 전위가 같은 두 점 사이에는 전류가 흐르지 않는다. → [본문](#휘스톤-브리지는-전위가-같은-두-점을-찾는다)
- 휘스톤 브리지 평형 조건 $R_1R_3 = R_2R_4$ (마주 보는 변의 곱이 같다). 전원 전압과 무관하다. 검류계가 0이 되게 맞춰 모르는 저항을 정밀하게 잰다. → [본문](#휘스톤-브리지는-전위가-같은-두-점을-찾는다)
- 평형 브리지의 가운데 소자는 떼어 내도(또는 단락해도) 회로가 그대로다. 평형일 때만 그렇다. → [본문](#휘스톤-브리지는-전위가-같은-두-점을-찾는다)

## 스스로 설명해보기

1. 실제로는 전자가 (−)극에서 (+)극으로 움직이는데, 왜 전류의 방향을 (+)극에서 (−)극으로 정한 관례를 지금도 그대로 쓰는가?
   <details><summary>답</summary>

   전류의 방향은 전자가 발견되기 전에 "(+) 전기가 흐른다"는 가정으로 정해졌다. (−) 전하가 한쪽으로 움직이는 것과 같은 양의 (+) 전하가 반대쪽으로 움직이는 것은 단면을 지나는 전하량의 변화와 회로에 미치는 효과가 똑같다. 그래서 관례를 바꾸지 않아도 계산 결과가 틀리지 않으므로 그대로 쓴다.

   </details>

2. "직렬에서는 전류가 같다", "병렬에서는 전압이 같다"는 각각 키르히호프의 어느 법칙에서 나오고, 왜 그런가?
   <details><summary>답</summary>

   직렬은 KCL에서 나온다. 직렬 연결점에는 들어오는 길과 나가는 길이 하나씩뿐이라, 전하 보존에 따라 들어온 전류가 그대로 나간다. 병렬은 KVL에서 나온다. 병렬 소자들은 양 끝이 같은 두 점에 이어져 있으므로, 각 소자와 전원이 이루는 폐회로에서 전압강하가 모두 같은 전위차가 된다.

   </details>

3. 같은 전압의 콘센트에 꽂는 전기기구 가운데 전력이 큰 것의 저항은 큰가, 작은가? $I^2R$을 보면 저항이 클수록 전력이 커 보이는데 무엇이 다른가?
   <details><summary>답</summary>

   작다. 가정의 기구들은 병렬로 같은 전압을 받으므로 $P = \frac{V^2}{R}$으로 보아야 하고, 저항이 작을수록 전력이 크다. $I^2R$은 직렬처럼 전류가 같은 경우에 비교하기 좋은 꼴이다. 전압이 같은 경우에는 저항이 작아지면 전류가 커져서 $I^2$가 더 크게 늘어나므로 $I^2R$로 계산해도 결과는 같다.

   </details>

4. 전압계는 내부저항이 크고 병렬로, 전류계는 내부저항이 작고 직렬로 연결한다. 내부저항의 크기와 연결 방법이 왜 짝을 이루는가?
   <details><summary>답</summary>

   계기는 원래 회로를 바꾸지 않아야 한다. 병렬로 단 전압계는 전류를 빼앗지 않아야 하므로 저항이 커야 하고, 직렬로 끼운 전류계는 전압을 잡아먹지 않아야 하므로 저항이 작아야 한다. 같은 이유로 배율기는 큰 저항을 직렬로 달아 전압을 나눠 맡고, 분류기는 작은 저항을 병렬로 달아 전류를 나눠 맡는다.

   </details>

5. 휘스톤 브리지가 평형이면 가운데에 어떤 저항이 있든 떼어 내고 합성저항을 계산해도 되는 이유는 무엇인가?
   <details><summary>답</summary>

   가운데가 없을 때 평형 조건 $R_1R_3 = R_2R_4$이 성립하면 위쪽 길과 아래쪽 길이 전원 전압을 같은 비율로 나누므로 c와 d의 전위가 같다. 그 사이에 저항을 이어도 전위차가 0이라 전류가 흐르지 않고, 전류가 흐르지 않는 소자는 나머지 회로에 아무 영향을 주지 않는다. 그래서 떼어 내도(단락해도) 회로가 그대로다.

   </details>
