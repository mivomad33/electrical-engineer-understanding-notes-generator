# exam-sheets

교재 챕터 PDF 끝의 「단원별 기출 문제풀이」로 두 가지 PDF를 만든다.

| 파일 | 내용 |
|---|---|
| `chNN-questions.pdf` | 문제지: 해설 상자와 정답 표시를 흰색으로 가린 문제 페이지 |
| `chNN-answers.pdf` | 정답·해설: 1쪽은 정답표(번호, 정답, 해설 위치), 2쪽부터 원본 문제풀이 페이지 |

문제지는 고해상도 이미지로 다시 만든 PDF라서, 가린 해설이나 정답이 텍스트로도 남지 않는다.

설계와 근거, 결정 기록은 [PLAN.md](PLAN.md)에 있다.

## 준비

[uv](https://docs.astral.sh/uv/)만 있으면 된다. 첫 실행 때 `uv run`이 가상환경(`.venv/`)을 만들고 PyMuPDF를 설치한다.

## 사용법

이 폴더(`tools/exam-sheets/`)에서 실행한다.

과목 폴더 전체를 처리하려면:

```bash
uv run exam_sheets.py ../../textbook/회로이론
```

챕터 하나만 처리하려면:

```bash
uv run exam_sheets.py ../../textbook/회로이론/회로이론_제01장_전기이론.pdf
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--dpi` | `200` | 문제지 렌더링 해상도. 인쇄용이면 `300` |
| `--out` | `output/` | 산출물 폴더 |

산출물은 `output/{과목 폴더}/`에 생긴다(예: `output/circuit-theory/ch01-questions.pdf`). 같은 명령을 다시 실행하면 덮어쓴다.

## 실행 결과 읽기

```
ch01 전기이론: 문제 9개, 페이지 PDF p.15~, 가린 해설 상자 9개 → ch01-questions.pdf, ch01-answers.pdf
```

이상이 있으면 해당 챕터 아래에 `경고:` 줄이 붙는다. 경고가 하나라도 있으면 종료 코드는 1이다. 경고의 종류는 다음과 같다.

| 경고 | 의미 | 할 일 |
|---|---|---|
| `해설 상자 N개, 정답 M개` | 한 페이지에서 가린 상자 수와 정답 표시 수가 다르다 | 그 페이지의 문제지를 열어 덜 가렸거나 더 가린 곳이 있는지 확인한다 |
| `문제 번호가 01부터 연속되지 않는다` | 문제 번호를 놓쳤거나 잘못 읽었다 | 정답표가 어긋났을 수 있다. 원본과 대조한다 |
| `NN번 정답을 찾지 못했다` | 정답 기호를 읽지 못했다 | 정답표에 `?`로 표시된다. 해설 페이지에서 직접 확인한다 |
| `짝지을 문제 번호가 없는 정답` | 정답 앞에 문제 번호가 없다 | 위와 같다 |
| `…에 텍스트가 남아 있다` | 문제지에 텍스트가 남았다(가린 내용이 새어 나갈 수 있음) | 코드 문제다. 고치기 전에는 문제지를 쓰지 않는다 |

경고가 없어도 새 과목을 처음 돌렸을 때는 문제지 몇 쪽을 열어 눈으로 확인하는 것이 좋다.

## 새 과목·챕터 추가

- 입력 PDF 파일명은 `{과목}_제{NN}장_{장 제목}.pdf` 형식이어야 한다. 교재 원본 파일명이 이 형식이다.
- 새 과목은 [`tools/subjects.json`](../subjects.json)에 `"과목": "영문-폴더명"`을 추가한다 (note-pdf도 이 파일을 쓴다). 프로젝트 `CLAUDE.md`의 과목 폴더 표와 같은 이름을 쓴다. 추가하지 않으면 한글 과목명이 그대로 폴더명이 된다.
- 레이아웃이 다른 교재라서 경고가 나오면 PLAN.md 「핵심 알고리즘」의 규칙(해설 상자 색, 정답 표시 위치, 문제 번호 크기)을 확인하고 상수를 고친다.

## 주의

- 교재 원본(`textbook/`)은 읽기만 한다.
- 산출물에는 교재의 구매자 워터마크가 그대로 남는다. 개인 학습용으로만 쓰고, 공유하거나 커밋하지 않는다. `output/`과 `.venv/`는 git에서 제외되어 있다.
- 로그에는 페이지 텍스트를 출력하지 않는다. 디버깅 코드를 추가할 때도 이 원칙을 지킨다.
