# split-textbook

교재 원본(`textbook_original/`의 과목 책)을 챕터별 PDF로 잘라 `textbook/{과목}/{과목}_제NN장_{제목}.pdf`에 넣는다.
노트 작업(`/chapter-note`), exam-sheets, note-pdf는 모두 이 챕터 PDF를 쓴다.

설계와 근거(챕터 경계를 찾는 방법, 참고 분할본과의 대조 등)는 [docs/changes/2026-10-21-split-textbook.md](../../docs/changes/2026-10-21-split-textbook.md)에 있다.

## 준비

[uv](https://docs.astral.sh/uv/)만 있으면 된다. 첫 실행 때 `uv run`이 가상환경(`.venv/`)을 만들고 PyMuPDF를 설치한다.

## 사용법

이 폴더(`tools/split-textbook/`)에서 실행한다. 먼저 계획 표만 본다 (파일을 쓰지 않는다).

```bash
uv run split_textbook.py
```

표가 맞으면 실제로 자른다.

```bash
uv run split_textbook.py --apply
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| 위치 인자 | `textbook_original/` | 원본 책 PDF 또는 폴더 |
| `--out` | `textbook/` | 챕터 PDF를 넣을 폴더 |
| `--apply` | 없음 | 계획만 보이지 않고 실제로 자른다 |

- 책마다 "과목 · 장 · 제목 · 원본 쪽 · 쪽 수 · 기존 파일" 표를 보여 준다.
- 새 파일만 쓴다. 같은 과목·장의 파일이 이미 있으면 내용(쪽마다 텍스트 해시)을 비교해, 같으면 그대로 두고 다르면 덮어쓰지 않고 알린다. 노트에 적힌 `PDF p.N` 쪽 번호가 바뀌지 않게 하기 위함이다.
- 오류(목차 장 수와 표지 수 불일치, 과목 이름을 못 읽음, `tools/subjects.json`에 없는 과목 등)가 있는 책은 자르지 않는다. 종료 코드는 1이다.
- 앞부분(표지·머리말·목차), 부록(찾아보기), 판권은 자르지 않는다.

## 챕터를 찾는 방법 (요약)

- **표지 쪽**: 한 색으로 쪽 전체를 칠한 쪽이 챕터 표지다 (원본에 책갈피가 없다).
- **장 목록과 제목**: 표지 앞 앞부분의 목차 쪽에서 `제NN장`과 그 아래 제목 줄을 읽는다. 한 권에 과목이 둘이면(회로이론 및 제어공학) 앞부분이 두 번 나오고, 각각이 과목 하나의 장 목록이 된다.
- **챕터 범위**: 표지부터 다음 표지 전의 마지막 챕터 쪽까지. 챕터 쪽은 꼬리말 "속전속결 필기 이론서" 또는 "강의보기"가 있는 쪽이다. 그래서 챕터 끝의 빈 쪽과 다음 과목 앞부분은 빠진다.
- **과목 이름**: 본문 머리말 "회로이론 | 제1장 …"의 `|` 앞부분.
- **파일명**: NFC로 쓴다 (원본 파일명은 NFD).

## 교재 개정판이 나오면

원본을 `textbook_original/`에 바꿔 넣고 계획 표부터 본다. 레이아웃이 바뀌어 오류가 나면 `split_textbook.py` 위쪽 상수(꼬리말 문구, 표지 색 비율, 목차 제목 줄 간격)를 확인한다.
기존 챕터 파일과 내용이 달라지면 덮어쓰지 않으니, 노트의 쪽 번호를 어떻게 할지 먼저 정하고 기존 파일을 옮긴 뒤 다시 실행한다.

## 주의

- 원본과 결과물 모두 교재 저작물이고 구매자 워터마크가 있다. 커밋하지 않는다 (`textbook/`, `textbook_original/`, `*.pdf`는 git 제외).
- 로그에는 교재 본문 텍스트를 출력하지 않는다. 출력하는 것은 목차의 장 제목, 머리말의 과목 이름, 쪽 번호뿐이다. 디버깅 코드를 추가할 때도 워터마크·응원 문구 줄을 걸러야 한다.
