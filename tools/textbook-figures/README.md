# textbook-figures — 교재 그림을 노트에 넣을 PNG로

교재 챕터 PDF(`textbook/<과목>/<과목>_제NN장_….pdf`)에서 본문의 그림을 모두 찾아 잘라 낸다.
챕터 노트는 이 그림들을 빠짐없이 넣는다 (`CLAUDE.md` "교재 그림은 모두 넣는다", `/chapter-note` 1·4단계).
설계와 판정 규칙의 근거는 [docs/changes/2026-10-25-textbook-figures.md](../../docs/changes/2026-10-25-textbook-figures.md).

## 준비

[uv](https://docs.astral.sh/uv/)만 있으면 된다 (PyMuPDF는 처음 실행할 때 설치된다).

## 사용

```bash
cd tools/textbook-figures
uv run --quiet textbook_figures.py "../../textbook/회로이론/회로이론_제04장_비정현파 교류.pdf"   # 한 챕터
uv run --quiet textbook_figures.py ../../textbook/회로이론                                    # 과목 전체
```

결과:

| 위치 | 내용 |
|---|---|
| `notes/<과목 폴더>/figures/chNN/<id>.png` | 잘라 낸 그림 (300 DPI, PNG에 DPI를 적어 note-pdf가 인쇄 크기를 되살린다) |
| `notes/<과목 폴더>/figures/chNN/figures.json` | 필수 그림 목록(`figures`), 후보(`candidates`), 경고(`warnings`) |
| `.cache/work/<과목 폴더>/chNN-figures/sheet-*.png` | 점검 이미지: 교재 네 쪽씩, 찾은 그림을 색 상자로 표시 |

그림 폴더는 교재 저작물이라 git에 올리지 않는다 (`.gitignore`의 `notes/*/figures/`). 다시 실행하면 같은 그림이 다시 만들어진다.
실행할 때마다 그 챕터의 그림 폴더와 점검 폴더의 PNG를 지우고 새로 만든다.

| 옵션 | 뜻 |
|---|---|
| `--check <노트 파일>` | 챕터 노트(모든 파트)가 필수 그림을 빠짐없이 한 번씩 넣었는지 확인한다. 「통과」가 아니면 종료 코드 1 |
| `--grid <쪽>` | 그 PDF 쪽에 20pt 눈금과 찾은 상자를 겹친 이미지(`grid-pNN.png`)를 점검 폴더에 만든다. manual.json 좌표를 읽을 때 쓴다 |
| `--no-audit` | 점검 이미지를 만들지 않는다 |
| `--out <폴더>`, `--work <폴더>` | 그림·점검 이미지를 다른 곳에 만든다 (시험용) |

## 무엇을 그림으로 보나

| id | 종류 | 점검 이미지 색 | 필수 |
|---|---|---|---|
| `fig4-1` | 캡션 「그림 4-1」 위의 그림 | 빨강 | 예 |
| `tab4-2` | 「표 4-2」 중 곡선·사선·이미지(파형, 소자 기호 등)가 든 표 | 초록 | 예 |
| `p05-1` | 캡션 없는 그림 (PDF 5쪽의 첫째). TIP 상자 안 그림, 단계별 회로 등 | 파랑 | 예 |
| manual.json `add`의 id | 직접 지정한 그림 | 보라 | 예 |
| `tab4-3`, `p07-1` | 그림 없는 표, 표시 없는 표(루스 표, 공식 상자 등) | 회색 | 아니오 (노트가 마크다운 표·수식으로 다시 쓴다) |

- 대상은 본문 쪽뿐이다. 장 표지, 강의 QR 쪽, 기출 문제풀이 쪽(문제지 PDF가 따로 있다)은 보지 않는다.
- 캡션 그림은 캡션 위의 도형 덩어리를 위로 이어 모으고(하위 그림 사이의 (a)·[…] 소제목 줄은 건너뛴다), 그림 속 라벨을 더한다. 그림 속 라벨 글꼴(바탕체 계열)은 본문에 쓰이지 않아서, 길어도 라벨로 본다. 캡션 줄은 잘라 낸 그림에 넣지 않는다 (노트가 캡션을 따로 쓴다).
- 표는 그림보다 먼저 찾아, 그림 옆의 표가 그림에 딸려 들어가지 않게 한다. 표 칸 안에 캡션이 있거나 캡션이 표 바로 아래 붙은 그림은 표 칸선을 경계로 찾고, 그 표는 그림들이 대신하므로 후보로 내린다.
- 공식에 딸린 도형(분수 막대, 형광 띠, 행렬 괄호 막대, 밑줄)과 글 상자(TIP, 공식 강조 상자)의 테두리는 그림으로 치지 않는다.

## 점검과 손으로 고치기 (manual.json)

자동 판정은 완벽하지 않다. 챕터마다 점검 이미지를 **모두** 보고 다음을 찾는다: 상자가 없는 그림, 그림을 자른 상자, 본문·수식·표까지 삼킨 상자, 그림이 아닌 파랑 상자, 여러 상자로 갈라진 그림, 그림이 들었는데 회색인 후보.
그림 옆의 범례·기호 설명은 그림의 일부로 본다 (빠졌으면 `rect`로 넓힌다). 이미 쓴 고침은 `manual.json`에 있고, 다시 실행해도 그대로 적용된다.
고칠 것은 `manual.json`에 적고 다시 실행한다. 형식 (과목 폴더 → 두 자리 장 번호 → 고칠 것):

```json
{
  "electrical-facility-standards": {
    "01": {
      "exclude": ["p10-1"],
      "merge": {"fig1-7": ["p14-1", "p14-2"]},
      "rect": {"fig1-10": [100, 330, 480, 470]},
      "add": [
        {"id": "p11-bar", "page": 11, "rect": [120, 580, 476, 674], "title": "시험전압 막대"},
        {"id": "p13-tab", "from": "p13-1"}
      ]
    }
  }
}
```

| 키 | 하는 일 |
|---|---|
| `exclude` | 필수 그림에서 뺀다 (그림이 아닌 것) |
| `merge` | 갈라진 상자들을 앞의 그림 영역에 합치고, 합친 상자는 필수에서 뺀다 |
| `rect` | 영역을 이 사각형으로 바꾼다 |
| `add` | 필수 그림을 더한다: `page`(PDF 쪽)와 `rect`, 또는 후보 id를 `from`으로 |

- 좌표는 PDF 포인트 `[x0, y0, x1, y1]`이다 (왼쪽 위가 원점, 쪽 크기 약 556×754). `--grid <쪽>` 이미지에서 읽는다.
- 적용 순서는 exclude → merge → rect → add이다. 없는 id를 가리키면 경고가 난다.
- 같은 문제가 여러 챕터에서 보이면 manual.json 대신 판정 규칙을 고친다.

## 안전장치

- 잘라 낼 영역에 워터마크·응원 문구로 보이는 글자(`@`, 7자리 이상 숫자, "응원합니다"), 머리말 자리(맨 위 60pt), 대각선 글자가 있으면 그 챕터를 멈춘다.
- 점검 이미지는 머리말 줄을 회색으로 가린다.
- 로그와 `figures.json`에는 교재 본문을 넣지 않는다 (캡션 제목만 넣는다).
