# 전기기사 필기 — 이해 노트

전기기사 필기 과목을 **처음부터 새로 쓰는 교재**로 공부하는 프로젝트다.

시험 대비 요약집(다산에듀 「속전속결」)은 공식만 나열되어 있고, 공식이 어디서 왜 나왔는지는 설명하지 않는다.
그래서 이 프로젝트는 각 챕터를 개념과 원리의 논리적 순서대로 다시 배열한다. 그리고 공식은 끊기지 않는 설명 속에서 유도한다.
기존 교재는 **범위**(무엇을 다뤄야 하나)와 **시험 표기**(시험지에서 어떻게 쓰이나)를 확인하는 데만 쓴다.

## 진행 현황

| 과목 | 완료한 챕터 | 목차 |
|---|---|---|
| 회로이론 | 1장 전기이론, 2장 정현파 교류, 3장 R-L-C 교류회로 | [notes/circuit-theory/_index.md](notes/circuit-theory/_index.md) |

전체 과목 목록과 과목 간 연결은 [notes/_index.md](notes/_index.md)에 있다.

## 노트 읽는 법

- 수식은 KaTeX 문법이다. **VS Code 마크다운 미리보기**로 열면 수식이 렌더링된다.
- 과목 `_index.md`의 챕터 목차에서 시작한다. 챕터가 여러 파일로 나뉘어 있으면 `-1`부터 순서대로 읽는다.
- 각 노트의 구성은 다음과 같다.
  - **본문**: 처음 이해할 때 처음부터 끝까지 읽는 글이다. 큰 질문 → 이야기 뼈대 → 마디별 설명 순서다.
  - **부록**: 복습용이다. 정리 목록, 교재 범위 대응표, 스스로 설명해보기, 연결로 이뤄진다.
- 본문 중간의 `> **헷갈림 주의**`는 막히기 쉬운 지점이다. `> **시험 표기**`는 교재·시험에서 같은 내용을 어떻게 쓰는지 알려 준다.

## 새 챕터 노트 쓰기

[Claude Code](https://claude.com/claude-code)에서 교재 챕터 PDF를 넣어 스킬을 실행한다.

```
/chapter-note textbook/회로이론/회로이론_제04장_…….pdf
```

스킬은 범위 추출 → 설계 → 집필 → 마무리의 4단계로 진행한다. 작업 파일(`.cache/work/`)이 남아 있으면 중단된 단계부터 이어간다.
노트의 모습에 관한 규칙은 [CLAUDE.md](CLAUDE.md)에, 만드는 절차는 [SKILL.md](.claude/skills/chapter-note/SKILL.md)에 있다.

## 기출 문제 풀기

[tools/exam-sheets](tools/exam-sheets/README.md)는 교재 챕터 끝의 기출 문제풀이로 PDF 두 개를 만든다.
- 문제지: 해설과 정답을 가린 문제 페이지
- 정답·해설: 정답표 뒤에 원본 해설 페이지를 붙인 것

```bash
cd tools/exam-sheets && uv run exam_sheets.py ../../textbook/회로이론
```

## 저작권과 개인정보

- `textbook/`의 교재 PDF는 저작물이다. 수정하지 않고, 커밋하지 않는다(`.gitignore`로 `*.pdf` 제외).
- 교재 페이지에는 구매자 개인정보 워터마크가 들어 있다. 이 워터마크는 노트, 작업 파일, 커밋 어디에도 옮기지 않는다.
- 교재 페이지에서 만든 산출물(`.cache/`, `tools/exam-sheets/output/`)은 개인 학습용이며 git에서 제외되어 있다.
- 노트는 교재 문장을 옮기지 않고 모두 새로 쓴다.
